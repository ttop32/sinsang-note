## 4. 이번에 새로 걸린 함정

1. 🆕 **`<frameset>` 껍데기가 한글 도메인을 숨긴다** — 천안당 `cheonandang.com` 437B 의 `<frame src>` 가 퓨니코드였다.
   meta refresh 만 찾지 말고 `frame`/`iframe` 의 `src` 도 따라가라.
2. 🆕 **인증서 만료 3곳**(호두가·아뜨베·킴브로스 선례). 3차가 "중간 인증서 누락일 수 있다"고 적었던 호두가·아뜨베는
   **만료**였다 — `certs/` 로는 못 고친다. 둘 다 http 로 보면 내용이 없어서 받을 이유도 없다.
3. 🆕 **주차 도메인은 시간이 지나며 바뀐다** — 핫브레드는 1주일 사이에 AWS 타임아웃 → hosting.kr 주차로 바뀌었다.
4. 🆕 **프차몰 링크가 브랜드가 아니라 모회사를 가리킨다** — 마크빈 → 훌랄라치킨, GLOER → WD(회사 소개).
5. 🆕 **`sMode` 같은 숨은 파라미터** — 숲속호두는 내비 링크의 `sMode=SELECT_FORM` 을 빼면 빈 본문 200 이다.
   검색엔진·노트에 남은 주소를 그대로 믿지 말고 **내비 링크를 다시 읽어라.**
