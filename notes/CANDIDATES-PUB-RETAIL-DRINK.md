### 1-1. ⚠️ `fruityom.com` 은 **중간 인증서를 잘못 보낸다** (선례 5번째)

```
leaf  CN=fruityom.com
      issuer = Sectigo RSA Domain Validation Secure Server CA
chain 서버가 보낸 1번 = Sectigo Public Server Authentication CA DV R36   ← 발급자가 아니다
```
`unable to get local issuer certificate` 로 붙지 않는다. AIA
(`http://crt.sectigo.com/SectigoRSADomainValidationSecureServerCA.crt`)에서 진짜 발급자를
받아 certifi 에 **더하면** 검증을 켠 채로 붙는다(실측 200 / 20,813B). **`verify=False` 는 쓰지 않았다.**
다만 **내용이 없어서 어댑터를 만들지 않았으므로 `collectors/certs/` 에는 넣지 않았다.**
나중에 이 사이트를 다시 열 사람은 위 URL 로 받으면 된다(만료 2030-12-31).

### 1-2. 🔴 이 업종에서 새로 확인한 함정 — **"패스오더 점포 페이지"**

소형 음료 브랜드는 본사 사이트 대신 **주문 플랫폼 점포 페이지**(`app.passorder.co.kr`)가
검색 상위에 뜬다. 200 이고 `<title>` 에 브랜드명이 들어 있어 **공식 사이트로 착각하기 쉽다.**
실제로는 `요커 교대점`·`프루쉬 센텀점` 처럼 **점포 단위**이고,
출시일·NEW 배지가 없으며 점포마다 메뉴가 다르다. 도메인 오인(함정 9)의 변종이다.
같은 자리에 **당근 동네업체·구글 사이트·카카오 채널**도 뜬다. 셋 다 브랜드 소스가 아니다.

### 1-3. 📏 어디까지 봤나

- **음료(커피 외) — 가맹점 5개 이상 33곳 전부에 결론이 있다. 안 본 곳은 0곳이다.**

## 2. 주점 — 🔴 **"메뉴가 이미지뿐이라 OCR 없이 불가"는 틀렸다. 판정을 뒤집는다**

### 2-0. 먼저 결론

기존 기록(`CANDIDATES-CAFE2.md` §8-6 · `COVERAGE-SUMMARY.md` · `CRAWLING-POLICY.md` §6-4 ·
`ROADMAP.md`)은 **투다리·청담동말자싸롱·생활맥주 3곳**을 보고 "주점 전반은 메뉴가 이미지라
OCR 없이 불가"로 업종 전체를 접었다. **표본 3곳으로 500개 업종을 판정한 것이고, 틀렸다.**

이번에 **26곳을 직접 열었고 그중 8곳이 상품명 텍스트를 DOM 으로 준다.**

| | 곳 |
|---|---:|
| 실제로 연 곳 | **26** |
| 상품명 텍스트가 **DOM 에 있는** 곳 | **8** (31%) |
| 메뉴가 이미지뿐 / 메뉴 페이지 자체가 없음 | 12 |
| 음식 브랜드가 아님(홀덤펍·노래방) | 3 |
| 도메인 미특정 · NXDOMAIN · 도메인 오인 | 3 |

**다만 "텍스트가 있다"와 "어댑터가 된다"는 다르다.** 8곳 중 **신상 신호(배지·날짜·신메뉴 칸)가
있는 곳은 월간맥주 단 1곳**이다. 나머지 7곳은 **배지도 날짜도 전혀 없는 고정 메뉴판**이라
긁으면 그대로 제1 규칙 위반(메뉴판 전체를 신상으로 내보내기)이 된다. 그래서
**"OCR 때문에 불가"가 아니라 "신상 신호가 없어서 불가"로 사유를 고쳐 적어야 한다.**
사유가 다르면 다시 열어 볼 시점도 다르다 — OCR 은 영영 안 할 수도 있지만,
브랜드가 `[NEW]` 배지 하나만 달면 7곳은 바로 열린다.

### 2-3. 이 업종에서 새로 확인한 것

1. **원페이지 랜딩이 주점의 기본형이다.** 일일수작·이태리양조장·잔잔·한라맥주·한남동그집 —
   홈 한 장이 200KB~1.4MB 고 메뉴가 그 안의 `#앵커`다. 상품 DOM 이 아예 없다.
   "JS 렌더라서 못 읽는다"가 아니라 **처음부터 상품 단위로 만들지 않은 사이트**다.
2. **게시판은 있는데 쓰는 용도가 다르다.** 별난아재맥주는 날짜가 또렷한 게시판을 20건 넘게
   굴리는데 내용이 **전부 점포 오픈·계약 공지**다. 호맥도 `[OPEN]` 이 `[NEW]` 보다 많다.
   주점 본사에게 게시판은 **상품 공지가 아니라 가맹 영업 채널**이다.
3. **술이 섞여 들어온다.** 호맥 `[NEW]` 3건 중 2건, 오늘와인한잔 메뉴 목록의 대부분,
   1도씨·촌댁맥주 메뉴의 `주류` 칸. 이 업종 어댑터는 **주류 칸을 빼는 처리가 필수**다.
4. **"메뉴가 이미지뿐"과 "신상 신호가 없다"를 구분해서 적어야 한다.** 둘은 다시 열어 볼
   시점이 다르다. 기존 기록은 둘을 뭉뚱그려 업종 전체를 닫았다.

## 4. 만든 것 — `collectors/pub_monthlybeer.py` (월간맥주)

이번 범위 전체(주점 26 + 유통 PB 27 + 음료 5 = **58곳**)에서 어댑터가 선 곳은 **1곳**이다.

| 항목 | 값 |
|---|---|
| 파일 | `collectors/pub_monthlybeer.py` |
| 브랜드 | 월간맥주 (삼정프랜차이즈, 광주) · 가맹점 **60개** |
| 분류 제안 | 유형 `FRANCHISE` / 세부분류 **`안주`** (`taxonomy.SUBS` 에 이미 있는 칸) |
| 소스 | `https://www.monthlybeer.co.kr/product/list?ca_id=<01..10>[&page=N]` |
| 건수 | **68건** (칸별 7+7+11+7+9+8+1+2+6+10 = 68, 전체 목록 9쪽 68건과 일치) |
| 신상 신호 | 상품명 앞 **`[NEW]` 말머리 — 7건 / 68건 = 10.3%** |
| 날짜 | **없다.** `released_at`·`uploaded_at` 둘 다 비움 |
| 요청 수 | 카테고리 10칸 × 1~2쪽 ≈ **12회**, `DELAY=1.5s` |

검증 출력(2026-10-08):
```
68
True  | 피자/파스타 | 크레이지핫치킨 패스츄리피자
True  | 튀김류     | 숙주산더미탕수육 / 우삼겹표고계란전 / 갈릭버터치즈통감자
True  | 탕류       | 칼칼고추장찌개 / 꼬지어묵김치우동
True  | 스낵류     | 허니고구마프라이
```

설계에서 조심한 것(전부 레포에서 난 사고 대응):

1. **`[NEW]` 만 턴다.** 같은 말머리 자리에 `[상하키친]` 3건(공동 브랜드)이 있다.
   대괄호를 통째로 털면 상품명이 깨진다 — 설빙 `span.flag` 혼입과 같은 자리.
2. **`[NEW]` 가 아닌 61건은 `is_new=None`.** `False` 로 두면 날짜가 전혀 없는 이 브랜드에서
   `rules.is_fresh` 의 `is_new is False` 분기가 `released_at` 을 요구해 **영구 0건**이 된다
   (더플레이스 사고). `None` 이면 diff 경로로 떨어진다.
3. **날짜를 지어내지 않았다.** 사이트 어디에도 등록일이 없고 이미지 파일명도 해시다.
   오늘 날짜를 넣으면 68건이 통째로 60일 창에 들어온다.
4. **가드 5개 전부 `raise`** — 카테고리 8칸 미만 / 상품 50건 미만 / `[NEW]` **0건** /
   `[NEW]` 50% 초과 / 사진 90% 미만. "조용한 빈 리스트 금지" 규칙대로다.
5. **술 칸 차단.** 지금은 없지만 주점이라 언제든 생긴다(`_ALCOHOL_CATES`).
   호맥은 `[NEW]` 3건 중 2건이 맥주였다.
6. **페이징을 마크업에서 읽었다.** `div.paging` 이 `/_subpage/kor/product/list.php?…&page=N`
   라는 다른 경로를 가리키는데, `/product/list?ca_id=..&page=N` 로도 같은 결과가 온다(실측).
   한화갤러리아 때처럼 "같은 바이트 = 페이징 없음" 으로 단정하지 않았다.
7. **`.attributes.get(k) or ""`** — selectolax 가 값 없는 속성에 `None` 을 준다(태리로제떡볶이 56건 증발).

⚠️ **레지스트리 배선은 하지 않았다.** `collectors/base.py`·`collect.py`·`taxonomy.py` 는 읽기만 했다.
등록 담당이 `BRANDS` 에 `"월간맥주": (FRANCHISE, "안주")` 와 `SITES` 를 넣어야 화면에 뜬다.
📌 **`안주` 는 `taxonomy.SUBS` 에는 있지만(편의점이 쓰는 칸) FRANCHISE 세부분류로는 신설값이다**
(기존 11종: 한식·치킨·분식·일식·햄버거·샌드위치·피자·양식·도시락·중식·샐러드). 신설할지
기존 칸에 흡수할지는 등록 담당 판단이다.
