# 재검토 — robots·약관으로 접었던 제조사·유통 8곳

운영자가 2026-10-02 에 robots·약관 무시를 승인했다. 1·2차가 **robots 만 보고**
접은 8곳을 **① 제품 카탈로그 ② 보도자료·뉴스룸 두 경로를 다 열어** 다시 본다.
1차 "불가" 를 믿지 않는다 — 삼양·크라운·해태·풀무원·빙그레가 전부 그 길로 뒤집혔다.

진행 상황을 브랜드 하나 끝낼 때마다 여기 덧붙인다.

---

## ① 제주개발공사(제주삼다수) — ❌ **어댑터 안 만듦** (robots 사유는 해소, **출시 밀도 0**)

원래 사유: `notes/CANDIDATES-MAKER.md` §⑬ · `notes/MAKER-SNACK-DRINK.md` —
`https://www.jpdc.co.kr/robots.txt` 가 `User-agent: * → Disallow: /`,
검색봇 4종(Googlebot·Daumoa·Bingbot·Yeti)만 허용목록. **그래서 본문을 한 번도 안 열었다.**

### 실측 (2026-10-08)

```
GET https://www.jpdc.co.kr/              200     87B   ← ⚠️ 본문이 meta refresh 껍데기뿐이다
    <meta http-equiv="refresh" content="0;url=https://www.jpdc.co.kr/index.htm"/>
GET https://www.jpdc.co.kr/index.htm     200  96,742B  <title>제주특별자치도개발공사</title>
```
**apex 를 그대로 받고 "87바이트 = 빈 사이트" 로 읽으면 안 된다.** httpx 의
`follow_redirects` 는 meta refresh 를 안 따라간다. `/index.htm` 을 직접 쳐야 한다.

대체 도메인 3개도 쳤다 — `www.samdasoo.co.kr` **ConnectTimeout** ·
`www.jejusamdasoo.co.kr` **ConnectTimeout** · `www.jeju-samdasoo.com` **NXDOMAIN**.
`jejusamdasoo.com` 은 200(29,456B) 인데 **`제주삼다수 가정배송` 주문몰**이다(신상 축 아님).

### 경로 둘 다 열었다

| 경로 | URL | 결과 |
|---|---|---|
| 제품 카탈로그 | `/business/water/samdasoo.htm` | **카탈로그가 아니다.** 브랜드 소개 1장. 상품 목록·날짜·배지 전부 없음 |
| 공사소식/공지사항 | `/open/news/notice.htm` | 전건이 **입찰·임대주택 예비입주자·평가위원 명단**. 상품 0건 |
| **보도자료** | `/happy/pr/report.htm` | ✅ **살아 있다** — 총 1,501건, 최신 2026-10-06. 서버 검색 `?q=…&qType=title` 도 먹는다 |

⚠️ 보도자료는 메뉴 `홍보 > 보도자료` 아래라 `/open/news` 쪽을 봐서는 안 보인다.
1·2차가 robots 에서 멈춘 탓에 **이 보드의 존재 자체가 기록에 없다.**

### 🔴 그런데 출시 밀도가 0이다 — 이게 탈락 사유다

`?q=출시&qType=title` 전수 **15건(2018-08-31 ~ 2025-11-13)**. 7년에 15건이다.
최근 2년치를 눈으로 읽으면 **진짜 신제품이 하나도 없다**:

```
2025-11-13  제주삼다수, 김풍 '라면꼰대'와 손잡고 한정판 '고…   ← 한정판 라벨(콜라보)
2025-08-05  '가볍게 들고, 넉넉하게 즐긴다'… 제주삼다수, 소…   ← 소용량 용기
2025-07-23  제주삼다수, 광복 80년 기념 한정판 라벨 출시          ← 한정판 라벨
2024-07-08  제주삼다수X잔망루피, 콜라보레이션 한정판 라벨 출시    ← 한정판 라벨
2023-08-17  업계 최초 QR코드 도입한 무라벨 제품                 ← 포장 변경
2023-03-09  25주년 한정판 '한라산 에디션' 출시                  ← 한정판 라벨
```
`?q=선보` 3건 · `?q=신제품` **0건**.

**300일 창에 들어오는 출시 기사가 0건**이고, 2년을 넓혀도 전부 **라벨 에디션·포장
변경**이다. 크라운 `_REPACK_NAME`(에디션/한정판) 규칙을 그대로 적용하면 **전부 탈락**한다.
제품이 **먹는샘물 단일 라인**이라 구조적으로 신상 축이 없다 — 동아오츠카(45건에 1건)보다 낮다.

→ **어댑터를 만들지 않는다.** robots 는 더 이상 사유가 아니지만 **소스에 신상이 없다.**
   (유형, 세부분류) 값은 `MAKER`, `음료` 로 확인했다. 되살리려면 출시 기사가
   연 2건 이상으로 올라왔는지만 다시 세면 된다 — 경로는 위에 다 적었다.

## ② 광동제약 — ❌ **어댑터 안 만듦** (robots 사유는 해소, **보도자료 3년 정지 + 카탈로그에 날짜·배지 없음**)

원래 사유: `notes/CANDIDATES-DIRECT2.md` §62 — `www.ekdp.com/robots.txt`
`User-agent: * → Disallow: /` + Googlebot·naverbot·GPTBot 개별 허용목록.
농심·CJ와 같은 구조라 §6-4 로 제외. **본문은 안 열었다.**

### 실측 (2026-10-08) — 경로 넷을 다 열었다

```
GET https://www.ekdp.com/              200  85,654B → /main.do   <title>::: 광동제약 :::</title>
```

| 경로 | URL | 결과 |
|---|---|---|
| **보도자료** | `/PRcenter/news_list.do` | ⛔ **2023-11-15 에 멈췄다.** 총 82페이지·812건, 최신 seq 812 = 2023-11-15. 페이지 82 가 2002-10-18 로 **정렬은 내림차순이 맞다**(= 최신이 정말 3년 전) |
| 제품 카탈로그 | `/product/items_list.do?c1=6` (일반유통식품) | ⛔ **날짜도 배지도 없다.** 7페이지 × 9건 ≈ 63건. 본문 전체에 `new` 토큰이 CSS 클래스로만 존재, 상품 배지는 0건 |
| 제품 상세 | `/product/items_view.do?s=833` | ⛔ 등록일 없음. 원재료·주의사항만 |
| 공지사항 | `/membership/notice_list.do` | ⛔ **8건 전부 '개인정보처리방침 개정 안내'** |
| 직영몰 | `kwangdongmart.com` **신제품** 선반 `/shop/goodsList/001034000000000` | ⛔ **5건뿐 + 날짜 없음 + 전부 박스·행사**다(아래) |

⚠️ **`/PRcenter/news_list.do` 는 메뉴에 없다.** GNB 의 PR센터는 영상광고·Print광고·
공공기여시설·수탁뿐이고, 보드는 링크가 끊긴 채 살아만 있다. 폐기된 보드다.

### 직영몰 '신제품' 선반 전수 — 🔴 제1 규칙 위반이라 못 쓴다

```
썬키스트 병주스 100ml (오렌지레몬/피치리치)          13,900원
썬키스트 에너지 355ml 24입                   27%  21,900원
초당옥수수차 500ml 24입+6입 증정               11%  22,900원
광동 V라인 슬림핏 150ml 50입                 28%  53,900원
썬키스트 마시는 피스타치오 … 190ml 24입(선택 1)   55%  13,900원
```
**5건 중 4건이 할인율을 달고 있고 전부 24입·50입 박스**다. 이건 신제품 목록이 아니라
**직영몰 묶음 행사 선반**이다. 날짜가 한 건도 없어서 늙은 선반인지도 가릴 수 없다
(설빙 `icon_signature` 사고와 같은 자리). `광동 V라인 슬림핏` 은 본사 카탈로그
`s=833` 에 이미 있는 기존 상품이다.

### 판정

보도자료 = 3년 정지 · 카탈로그 = 날짜/배지 **구조적 부재** · 직영몰 = 행사 선반.
**세 경로 전부 신상 신호가 없다.** robots 는 더 이상 사유가 아니지만 **소스가 없다.**
(유형, 세부분류) 는 `MAKER`, `음료` 로 확인했다(의약품·건기식은 `c1=1·2·7` 로 분리돼
있어 `c1=6 일반유통식품` 만 쓰면 걸러진다 — 되살릴 때 쓸 수 있게 적어 둔다).

## ③ 금양인터내셔날 — ⛔ **범위 밖(주류 전업).** 어댑터 만들지 않음

지시대로 **비주류 품목을 파는지만** 한 번 보고 접는다.

```
www.kumyangint.com          NXDOMAIN
www.kumyanginternational.com NXDOMAIN
kumyang.com                 → dynadot 매각 안내 (남의 도메인)
www.keumyang.com            200  3,345B  euc-kr  <title>금양인터내셔날</title>   ← 진짜 도메인
    <meta name="Description" content="당신의 와인 가이드 - 금양">
    /mall/intro.ky = 성인인증 인트로. 본문이 "당신의 와인가이드" 한 줄이다
```
⚠️ 도메인이 `keumyang`(ㅡ 아님 ㅜ) 이다. `kumyang.com` 은 **매각 중인 남의 도메인**이라
거기서 받은 걸 금양으로 읽으면 안 된다(§도메인 오인 함정).

**와인 수입사 전업**이다. 사이트 자체가 성인인증 게이트 뒤에 있고 비주류 카테고리가 없다.
→ 본 프로젝트는 주류를 넣지 않으므로 **조사 종료. 어댑터 없음.**

카테고리: 막걸리 · 증류주/소주/리큐르 · 약주/청주 · 와인/과실주 · 선물세트

## ⑤ 머거본 — ❌ **어댑터 안 만듦** (⚠️ **1·2차가 본 도메인이 틀렸다** — 그래도 출시 밀도 0)

원래 사유: `notes/MAKER-SNACK-DRINK.md` §8 꼬리 조사 — "**robots 전면차단** `*: Disallow: /`".

### 🔴 먼저 — 1·2차가 본 건 **B2B 몰**이지 머거본 코퍼레이트 사이트가 아니다

```
www.murgerbon.co.kr          200  14,693B  euc-kr  <title>BtoB 로그인</title>
    robots.txt (48B): User-agent: *  /  Disallow: /  /  Disallow: /makeshop/   ← 1·2차가 읽은 것
    /shop/shopbrand.html?xcode=013…  **200 / 240B** 인데 본문이
        alert("로그인 후 이용하실 수 있습니다."); location.href='//www.murgerbon.co.kr';
      → 🔴 **200 이 성공이 아니다**(함정 ①)의 교과서 사례. 대리점 전용 makeshop 몰이다.

www.murgerbon.com            200 322,184B  UTF-8   <title>(주)머거본</title>   ← ✅ 진짜 코퍼레이트
```
⚠️ **철자가 `murgerbon`(mu**r**gerbon) 이다.** `muggerbon`·`mugerbon`·`머거본.kr/.한국/.com`
(퓨니코드 `xn--v69a94xn6b.*`) 전부 **NXDOMAIN** 이다. 로마자 추정으로는 못 찾는다.
**`.co.kr` 과 `.com` 이 서로 다른 사이트**다 — robots 는 `.co.kr` 쪽에만 있고,
`.com` 은 워드프레스(Salient 테마)로 완전 공개다.

### 두 경로 다 열었다

| 경로 | URL | 결과 |
|---|---|---|
| 제품 카탈로그 | `murgerbon.com/제품/` (전체) | ⛔ **약 80건이 한 장에 다 있고 날짜도 NEW 배지도 없다.** 꿀땅콩·맛땅콩·칼몬드 같은 30년 된 상품이 신상과 같은 줄에 있다 |
| **소식(뉴스룸)** | `murgerbon.com/소식/` (4페이지) | ✅ 보드는 **살아 있다**(최신 2026-04-24). 마크업도 깨끗하다 |
| WP REST | `murgerbon.com/wp-json/wp/v2/posts?per_page=100` | ✅ **200 / 17,689B, `x-wp-total: 40`** — 보드 전체가 한 번에 온다 |

### 🔴 전수 40건을 세서 탈락시킨다 — **출시 기사 3건, 전부 2020~2023**

`x-wp-total: 40`(2017-04-05 ~ 2026-04-24) 을 **한 건도 빠짐없이** 읽었다.
```
2023-09-08  머거본, 포켓몬스터 활용한 시즈닝 아몬드 4종 출시   ← 마지막 출시 기사. '4종' 이라 어차피 탈락
2020-02-11  [서울경제] 머거본과 롯데푸드의 협업 "커피땅콩 바" 출시
2020-01-31  [시민일보] ㈜머거본 신규브랜드 GLM, 신제품 프레첼 믹스 출시
2020-01-20  머거본, 라인 프렌즈와 협업 제품 출시
```
나머지 36건은 **공장 준공·본사 이전·산업단지 보상공고·CI 교체·마라톤/테니스 후원·
박람회·수상·매거진**이다. 카테고리도 둘뿐이다(`88`=소식 · `5`=머거본 매거진).

**최근 3년(2023-09-08 이후) 출시 기사 0건.** 300일 창은 당연히 0이다.
`notes/MAKER-SNACK-DRINK.md` §8 이 코스모스제과를 "50건 전수에 출시 1건(2020년)" 으로
떨어뜨린 것과 **같은 바**다. 보드가 살아 있어도 출시 축이 죽었다.
→ **어댑터를 만들지 않는다.**

### 되살릴 때 쓰라고 남기는 실측 (경로·셀렉터·함정)

GET https://murgerbon.com/wp-json/wp/v2/posts?per_page=100&_fields=id,date,title,link,categories

```

   본문 날짜와 2년 어긋난다(크라운 `YYMMDD` 함정과 같은 자리).
(유형, 세부분류) = `MAKER`, `과자` 로 확인했다(견과·육포·어포·스낵).

## ⑥ 이마트 — ❌ **어댑터 안 만듦** (robots 사유는 해소, **상품 축 부재 + 보도자료에서 상품명이 안 나온다**)

`company.emart.com` robots `User-agent: * → Disallow: /`(Yeti·Googlebot만 허용).

```
https://company.emart.com/      200     254B  ← ⚠️ JS 리다이렉트 껍데기 (document.location.href="/ko/main.do")
https://company.emart.com/ko/main.do  200 30,250B  <title>이마트 회사소개</title>
