- 작업일: **2026-10-02**

## 1. 순위 — 무엇을 근거로 "상위권"이라 했나

순위 근거를 두 겹으로 깔았다. **둘 다 오늘 직접 받았다.**

### 1순위 소스 — 공정거래위원회 가맹사업거래 (`franchise.ftc.go.kr`)

```
GET /mnu/00013/program/userRqst/list.do?selUpjong=21&selIndus=H1&pageUnit=9000&pageIndex=1
→ 200, 서버렌더 <table>, tbody tr = 582행
  첫 행: ['582', '마슬랜', '마슬랜', '이제현', '20110500042', '2011.10.04', '치킨']
```

**치킨 업종(`H1`) 정보공개서 등록 브랜드는 582개다.** 로그인 없이 한 번에 전수가 온다.

⚠️ 그런데 **이 표에는 가맹점 수가 없다.** 행이 주는 건 상호·영업표지·대표자·등록번호·최초등록일·업종뿐이다.
`FRANCHISE-MASTER.md` §2 가 적어둔 그대로이고, 오늘 다시 받아서 재확인했다.
가맹점 수는 정보공개서 **상세**에 있는데 그건 로그인이 걸린다.

### 2순위 소스 — 프차몰 `fchamall.com/franchise/치킨` (공정위 정보공개서 집계)

가맹점 수는 여기서 받았다. 페이지가 Next.js 라 RSC 페이로드에서 뽑았다.

```
GET https://fchamall.com/franchise/%EC%B9%98%ED%82%A8 → 200, 301KB
  JSON-LD: {"@type":"ItemList","name":"2026 치킨 프랜차이즈 순위","numberOfItems":269}
  푸터: "출처: 공정거래위원회 가맹사업거래시스템 / 매일 자동 갱신"
  ※ 각 업종에서 가맹점 5개 이상 운영 브랜드만 노출 → 치킨 268개
```

**`FRANCHISE-MASTER.md` 의 2026-09-30 판 순위와 1~30위가 순서·숫자까지 전부 일치했다.**
기억이나 노트를 믿지 않고 다시 받은 건 그 때문이고, 결과적으로 바뀐 게 없다는 것까지가 실측이다.
가맹점 수 기준일은 공정위 2025년도 정보공개서(= **2024년 말** 기준)다.

### 전체 순위표 (1~30위 + 업종이 갈린 맥시칸치킨)

맥시칸치킨은 공정위 업종이 **`기타 외식`** 이라 치킨 순위표에 안 들어간다. 하지만 치킨

## 3. 굽네치킨 8건 진단 — 버그가 아니다

운영자가 "굽네는 8건뿐이다, 수집이 제대로 되는지 확인해라" 라고 지목한 건이다. **파서 손실이 아니다.**

`collectors/chicken_goobne.py` 는 신제품 전용 페이지 `/menu/new_p?gubun=new_menu_list` 안의
JS 객체 `tabMenuData` 를 읽는다. 오늘 그 객체를 직접 까봤다.

```
tabMenuData 탭0(전체) = 8개
  seoul / new_original / pepper_boneless / boneless_chicago_pizza
  chicken_bake / chuchu_chicken_steak / new_combination / new_janggak
탭1(치킨) 5 + 탭2(피자) 2 + 탭3(사이드) 1 = 8   ← 합이 전체와 정확히 일치
```

**브랜드가 그 페이지에 올려둔 신제품이 정확히 8개다.** 어댑터는 8개를 전부 가져온다.
`fetch()` 실행 결과도 8건이고 이름·분류·이미지가 다 채워진다. 그중 4건은 썸네일 경로의
캠페인 폴더에서 날짜가 나온다(`/menu_new/260908_seoul/` → 2026-09-08, 그 외 260713·260618·260602).
나머지 4건은 상시 메뉴 이미지 경로라 날짜가 없다 — 어댑터 docstring 에 이미 적혀 있는 그대로다.

### 더 많이 긁을 길이 있긴 하다. 그런데 더 나쁘다

주문용 전체 메뉴 `/menu/menu_list` 는 **89건**이고, 거기엔 전용 페이지에 없는 신호가 있다 —
상품마다 `<span class="badge new">NEW</span>` 가 붙고 **89건 중 11건**이 달고 있다.
"8건이 적으니 이쪽으로 갈아타면 되겠다"는 생각이 바로 드는데, 11건을 눈으로 보면 안 된다.
