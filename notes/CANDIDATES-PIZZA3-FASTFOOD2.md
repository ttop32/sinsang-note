#### 🔴 `신메뉴` 탭(`ca_id=01`)은 포스터 1장이다 — 함정 3 그대로

```
GET /menu/list?ca_id=01   16,265B   ul.listType1 0건   prdtTotalCount = '0'
  → 본문이 <img src="/superboard/data/editor/2608/2026081721...">  포스터 한 장뿐
```
`ca_id=05`(모스의 아침)도 0건이다. 돈까스클럽과 같은 칸이라 **신메뉴 탭은 안 쓴다.**

#### 실제 상품 — 카테고리 목록 4칸, 54건 (2026-10-08 실측)

```
ca_id=02 버거        15건
ca_id=03 사이드      12건
ca_id=04 음료&디저트  12건
ca_id=06 세트        15건   ← rules.drop_sets() 가 본품 있는 세트를 턴다
ca_id=01 신메뉴       0건   ← 포스터
ca_id=05 모스의 아침   0건
```

#### 🔴 배지 — **맥락마다 다르다. 목록 페이지만 믿는다**

같은 상품의 배지를 세 자리에서 따로 셌다:

| 자리 | 배지 달린 비율 | 비고 |
|---|---:|---|
| 카테고리 목록 `/menu/list?ca_id=NN` | **4 / 54 (7.4%)** | ✅ 이것만 쓴다 |
| 상세 `?viewMode=view&idx=NN` 본문 | 4 / 8 표본 일치 | 같은 4건. `alt` 만 `HIT` 로 다르다 |
| 상세의 **`다른메뉴보기`** 블록 | **14 / 14 (100%)** | 🔴 템플릿이 무조건 찍는다 |

`다른메뉴보기` 는 **1972년부터 있는 간판 `모스버거`(idx 75)와 `와규치즈버거`(idx 28)에도
`기간한정` 을 달아 준다.** 조건 없이 렌더하는 깨진 템플릿이다. 퀴즈노스 66/66 과 같은 자리고,
여기서 긁었으면 메뉴판 전체가 신상이 됐다.

배지 요소는 `div.iconBox img[src="/images/icon-new.png"]` 하나인데 **`alt` 가 자리마다 다르다**
— 목록은 `기간한정`, 상세 본문은 `HIT`. 파일명은 `icon-new` 다. 셋이 다 다르니
**`alt` 값으로 판정하면 안 되고 목록 페이지에서 요소가 있느냐만 본다.**

배지 4건(2026-10-08): 하와이안베이컨치즈버거(idx 226) · 하와이안베이컨치즈버거 세트(227) ·
감자치즈고로케(228) · 저당수박에이드(229). **전체 54건 중 idx 가 가장 큰 넷이다** —
배지와 id 순서가 서로를 받쳐 준다.

## 훑은 방법 (다음 사람이 이어가라고 적어 둔다)

1. 프차몰 목록 `/franchise/<업종>?page=N` → 슬러그 전수(피자 108 · 패스트푸드 51).

   와 **공식 홈페이지 링크**. ⚠️ 홈페이지는 **일부 브랜드만** 들어 있다(뽕뜨락·바스버거·
   고피자·퀴즈노스 등). 빈 곳은 검색으로 따로 찾았고, 그래도 안 나오면 표에 **못 찾음**이라 적었다.

   `20\d\d-\d\d-\d\d` 꼴 날짜 수**를 센다. 셋 다 0이면 불가로 닫았다.
   ⚠️ 스크리너가 0을 뱉으면 **먼저 스크리너를 의심해라.** 7곳이 연속 0이 나와서
   텍스트 추출을 다시 확인했고(상품명이 제대로 뽑히고 있었다) 그제야 믿었다.
4. 신호가 있는 곳만 전수 수집해서 **배지 비율·날짜 분포를 직접 세고** 어댑터를 썼다.
