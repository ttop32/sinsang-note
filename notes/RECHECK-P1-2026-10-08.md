## 1. 올리페페 — 열리지 않았다 (CJ푸드빌 공용 API)

`collectors/korean_cheiljemyunso.py` docstring 이 적어 둔 그대로다. 같은 API 에 같은 모양으로 비어 있다.

```
GET https://brand-api.ivips.co.kr/menus/OLIPEPE/category?page=0&size=100
  → HTTP 200 / body status 200 / data.totalElements = 0 / totalPages = 0
GET https://brand-api.ivips.co.kr/menus/THEPLACE/category?page=0&size=100   (대조군)
  → totalElements = 7  (DESSERT/STEAK/PIZZA/RISOTTO&GNOCCHI/PASTA/ANTIPASTI/SALAD&SOUP)
```
대조군이 7칸을 주므로 **API·파라미터는 멀쩡하고 올리페페만 비어 있다.**

사이트도 다시 봤다.
```
https://www.olipepe.co.kr/?ssoLoginYN=N        200 / 23,770 B
https://www.olipepe.co.kr/menu?ssoLoginYN=N    404 / 14,629 B
https://www.olipepe.co.kr/menu                 404 / 14,629 B
```
🔴 **홈 HTML 안에 `menu` 라는 문자열이 0회, `메뉴` 도 0회다.** 링크가 Next.js 정적 자산과
favicon 뿐이고 **GNB 자체가 없다.** 즉 "경로를 잘못 찍은 것"이 아니라 **메뉴 화면이 아직 안 붙었다.**

> **다음 사람에게 — 재측정은 요청 한 번이면 끝난다.**
> `.../menus/OLIPEPE/category?page=0&size=100` 의 `totalElements` 가 0 이 아니면 그때
> `collectors/korean_cheiljemyunso.py` 를 복사해 `BRAND`·`SITE`·`BRAND_CODE`·`MIN_CATES`·`MIN_ITEMS`
> 만 바꾸면 된다. 0 이면 사이트는 열지도 마라.

## 2. 어더아사 — 도메인이 진짜로 없다. **종결한다**

지난 조사가 "DNS 12회 실패, 검색엔진엔 있음 → 재확인 필요"로 남긴 자리다. 권위 응답으로 끝냈다.

```
dig @8.8.8.8 xn--9m1b26w1qd0m.com A   →  status: NXDOMAIN   (어더아사.com)
dig @8.8.8.8 xn--9m1b26w1qd0m.kr  A   →  status: NXDOMAIN
어더아사.co.kr · eodeoasa.com · udeoasa.com · otheraisa.com  →  전부 gaierror
(대조군 kobongmin.com → 1.201.17.208 정상)
```
**NODATA 가 아니라 NXDOMAIN 이다** — 러너 DNS 의 간헐 실패가 아니라 도메인이 존재하지 않는다.

🔴 그리고 더 중요한 것: **1차 조사가 이미 이 사이트를 열어 봤고 판정까지 끝냈다.**
`notes/CANDIDATES-ICECREAM-BINGSU.md:59` —
> *한 장짜리 사이트다. 내부 링크가 전부 `#section1~7` 앵커고 게시판이 없다. '소식'도 앵커 →
> 신상 신호는 인스타그램(`@adas__official`)뿐 → 긁지 않는다*

즉 2차 조사의 "DNS 실패 → 재확인 필요"는 **1차 결과를 못 찾아서 생긴 중복 항목**이었다.
**판정은 A(구조적 불가) 로 이미 확정돼 있었고**, 지금은 도메인까지 사라졌으니 **D 로 옮기는 게 맞다.**
`COVERAGE-SUMMARY.md` 부록 A 의 아이스크림 칸에서 어더아사를 빼고 D 로 옮겨라. 합계는 불변.
