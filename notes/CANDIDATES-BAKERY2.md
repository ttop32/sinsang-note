## 2. 근거 (실측 조각)

### 2-1. 나폴레옹과자점 — 이 조사의 최대 수확

홈과 상품 페이지 둘 다 Next.js SSR 이고 `__NEXT_DATA__` 안에 데이터가 통째로 들어있다.

```
GET https://napoleonbakery.co.kr/h/b/napoleon/products?actions=REINIT  → 200, 546KB
props.pageProps.ssapidata.productpage = {"page":1, "pageSize":36, "total":354, "items":[…]}
```

`items[]` 의 필드는 `name / tags / productVariants / richimages / rowindex / key / _i18n` 인데,
**36건 중 3건에만 `day8until_newarrival` 이 붙는다.**

```json
{"name":"리치 캐러멜쉬폰",     "day8until_newarrival":20260831, "tags":["케이크","생크림 케이크"]}
{"name":"요거트복숭아생크림", "day8until_newarrival":20260815, "tags":["케이크","요거트 케이크","생과일 케이크"]}
{"name":"구운초코도넛",       "day8until_newarrival":20260831, "tags":["빵","숙성빵"]}
```

**브랜드가 직접 선언한, 날짜가 붙은 신상품 표식이다.** 이 조사에서 유일하다.

**⚠️ 다만 의미를 확정하지 못했다.** 필드명이 "day8 until newarrival" 이라
(가) 신상품 배지가 **끝나는 날**인지 (나) 시작일인지 (다) `8`이 노출 기간(8일/8주)인지 구분이 안 된다.
두 값(`20260831`, `20260815`) 모두 오늘(2026-09-30)보다 과거라 **(가) 종료일 쪽에 무게가 실리지만
확인 못 했다.** 어댑터를 붙일 때 며칠 관찰해서 값이 미래로 갱신되는지부터 봐라.
확정 전에는 `released_at` 이 아니라 **`is_new` 플래그로만** 써라.

태그 체계(`taxons` 50종)에 **`시즌한정`·`한정판`·`인기상품`** 이 따로 있어서 보조 신호가 된다.

**⚠️ 페이지네이션을 못 풀었다.** `?page=2` 를 붙여도 응답의 `page` 가 여전히 `1` 이고
같은 36건이 온다. 전체 354건을 받으려면 다른 방법이 필요한데 **찾지 못했다.**
1요청으로 36건(전체의 10%)만 확보되는 상태다.

robots 는 `/athena/`, `/orders/`, `/test$`, `/test/`, `/api/test$`, `/api/test/` 만 막는다.
`/api/test` 를 따로 막는다는 건 `/api/` 아래에 다른 것이 있다는 뜻인데 **찾지 못했다.**

푸터/데이터 확인: 사업자등록번호 **574-15-01858**, `venues` 45개(FACTORY 역할 포함).
**공정위 `제과제빵` 등록 목록에 없다** — 가맹사업이 아니라 직영 다점포로 보인다.

### 2-2. 브레댄코 — WordPress 는 열려 있는데 상품 타입이 없다

robots 가 파리바게뜨와 판박이다.

```
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php
Sitemap: https://www.breadnco.kr/sitemap.xml
```

REST API 도 열려 있다. 그런데 **등록된 post type 이 기본 4종뿐이다.**

```
GET /wp-json/wp/v2/types → 200
post(글) / page(페이지) / attachment(미디어) / wp_block(블럭)
```

**파리바게뜨의 `product` 커스텀 타입에 해당하는 것이 없다.** 1차의 최대 수확이 여기선 반복되지 않는다.

대신 **페이지 경로에 신제품이 분리돼 있다.**

```
/product/new-product/new-bread/      (제목: 빵)
/product/new-product/new-beverage/   (제목: 음료)
/product/new-product-beverage/       (제목: 신제품)
```

**⚠️ 이 페이지들의 `date` 는 2023-08 이다 — 페이지를 만든 날이지 상품이 나온 날이 아니다.**
`/product/new-product/new-bread/` 본문(89KB)을 받아봤지만 `/wp-content/uploads/` 아래
**2024년 이후 이미지가 하나도 없었다.** 상품이 어디서 렌더되는지 확인 못 했다.

미디어 API 에는 신호가 있다.

```
GET /wp-json/wp/v2/media?per_page=30&orderby=date&order=desc  → 200, 22건
2026-09-03T13:49:55  260902_추석_모바일용-BG          2026/09/260902_추석_모바일용-BG.jpg
2026-08-25T18:00:35  2608024_왁뿌소금빵_모바일배너     2026/08/2608024_왁뿌소금빵_모바일배너.jpg
2026-08-13T14:26:57  260720_초코바게트 포스터          2026/07/260720_초코바게트-포스터.jpg
```

파일명이 `YYMMDD_제품명_용도` 규칙이라 **신제품 프로모션 시점이 그대로 드러난다**
(왁뿌소금빵 2026-08, 초코바게트 2026-08). 다만 이건 **배너 이미지이지 상품 목록이 아니고**,
WP `date` 는 업로드 시각이다. `BRAND-CANDIDATES.md` §6-5 기준대로 **`uploaded_at` 까지만** 써라.

## 4. 규칙상 허용인데 의도는 정반대인 곳

1차의 앤티앤스와 같은 건이 **두 곳** 더 나왔다. 둘 다 `User-agent: *` 는 허용하면서
AI·데이터 수집 봇만 골라서 막는다. 우리 UA(`sinsang-note/1.0`)는 목록에 없으니 규칙상 허용이다.

**홍루이젠** — 고도몰이 넣어주는 기본 봇 정책이다.

```
# Default Bot Policy List provided by GODOMALL
User-agent: mj12bot
User-agent: SemrushBot
User-agent: ClaudeBot
User-agent: GPTBot
Disallow: /
```

이 그룹은 **브랜드가 아니라 솔루션 제공사(고도몰)가 넣은 기본값**이라
앤티앤스처럼 브랜드의 의사표시로 보기는 어렵다. 🟡 로 둔다.

**송사부고로케** — 이쪽은 주석까지 직접 달아서 손으로 넣은 티가 난다.

```
# 스팸/AI 봇 강력 차단
User-agent: MJ12bot … GPTBot / ChatGPT-User / CCBot / ClaudeBot / Bytespider
Disallow: /
```

**브랜드가 직접 쓴 것으로 보이므로 앤티앤스와 같이 취급해서 붙이지 않는 쪽을 권한다.** 🔴

### ⚠️ 아임웹 5곳의 이용약관은 받으면 안 된다

아임웹 사이트의 이용약관은 **`/?mode=policy`**, 개인정보처리방침은 `/?mode=privacy` 다.
그런데 robots 에 **`Disallow: /?mode*`** 가 있다.

`CRAWLING-POLICY.md` §6-2 가 지적한 두 번째 구멍이 정확히 여기다 —
`urllib.robotparser` 의 `can_fetch('/?mode=policy')` 는 **True 를 돌려주지만 실제로는 금지 경로다.**
`RuleLine` 의 `quote()` 가 `/%3Fmode%2A` 로 바꿔서 영원히 매칭되지 않기 때문이다.

**이 조사에서 실제로 걸려들 뻔했다.** 못난이꽈배기 약관을 받으려고 `/?mode=policy` 를
요청 목록에 넣었다가, 실행 도중 알아차리고 해당 요청이 나가기 전에 작업을 중단시켰다.
**아임웹 브랜드 5곳의 약관은 모두 "확인 못 함"으로 남긴다** — 받으면 robots 위반이다.

붙일 브랜드의 약관을 꼭 확인해야 한다면 robots 를 우회하지 말고
**브랜드에 직접 문의하는 경로**를 택해라.

## 7. 신제품 신호가 확실한 브랜드 (요약)

| 신호 종류 | 브랜드 |
|---|---|
| **날짜 (`released_at` 후보)** | **나폴레옹과자점** (`day8until_newarrival`, YYYYMMDD — ⚠️ 의미 미확정, §2-1) |
| **날짜 (`uploaded_at` 까지만)** | **브레댄코** (media API 파일명 `YYMMDD_제품명`) |
| **신제품 전용 페이지·카테고리** | **홍루이젠** (`cateCd=002`) · **브레댄코** (`/product/new-product/…`) |
| **NEW 배지 (`is_new`)** | **없음** — 1차에 이어 2차에서도 상품 카드에 살아있는 NEW 배지를 단 브랜드를 못 찾았다. 노티드는 배지가 **주석 처리**돼 있었고, 패션5는 **확인 못 함** |
| 신호 없음 | 노티드, 올드페리도넛, 아이엠도넛, 화이트리에, 못난이꽈배기, 삼송빵집, 김영모과자점, 도레도레 |
| 확인 못 함 | 패션5, 신라명과, 코코호도, 복호두, 송사부고로케, 로띠번, 따삐오 |

### WordPress REST API 가 열린 곳

**브레댄코 하나뿐이다**(`/wp-json/wp/v2/` 200). 그런데 **커스텀 `product` 타입이 없어서**
파리바게뜨처럼 상품+날짜를 한 번에 받는 구조가 아니다.
도레도레도 WordPress 이지만 **4.3.34** 라 REST API 가 코어에 들어오기 전 버전이고,
`/wp-json/` 요청에 서버가 연결을 끊었다.

## 8. 추천 순위

기준 순서는 **(1) 신제품 신호(특히 날짜) → (2) 수집 난이도 → (3) 인지도** 다.

| # | 브랜드 | 근거 | 상품 수 | 예상 요청 수 |
|---|---|---|---:|---|
| 1 | **나폴레옹과자점** | 이 조사에서 **유일하게 상품별 날짜 필드를 준다**(`day8until_newarrival`). `시즌한정`·`한정판` 태그가 보조한다. Next.js SSR 이라 1요청에 36건이 통째로 온다. 제과 명장 계보라 인지도도 있다. ⚠️ 페이지네이션 미해결이라 **당장은 36건까지** | 354 (접근 가능 36) | **1** |
| 2 | **브레댄코** | WordPress REST 가 열려 있고 **신제품 URL 이 분리**돼 있다(`/product/new-product/…`). media API 파일명이 `YYMMDD_제품명` 이라 프로모션 시점이 드러난다. 공정위 등록 58개점 정식 가맹본부 | 미확인 | 2~4 |
| 3 | **홍루이젠** | **신제품 전용 카테고리 URL**(`cateCd=002`)이 있고 `등록일순` 정렬이 된다. 가맹점 120개로 이번 조사 대상 중 2위. ⚠️ `Crawl-delay: 10` 을 지켜야 하고 고도몰 기본 봇 정책 확인 필요(§4) | 카테고리별 | 2 (신제품) / 7 (전체) |
| 4 | **노티드** | 신호는 **없다**(NEW 배지가 주석 처리). 그래도 4위인 건 **디저트 카테고리 인지도가 이 목록에서 압도적**이고 홈 1요청에 상품명+가격이 다 오기 때문이다. ⚠️ TLS 만료라 `http://` 로만 붙는다. 신제품은 diff 로만 잡힌다 | 홈에만 20+ | **1** |
| 5 | **삼송빵집** | 신호 없음. robots 가 `Allow:/` 뿐이라 제약이 가장 적고 `/doc/menu1~5.php` 5요청이면 전체가 온다. 설명·가격·알레르기 정보까지 붙어 있어 상품 레코드 품질이 좋다 | menu1 에 5종, 전체 미확인 | 5 |
| 6 | **올드페리도넛 · 아이엠도넛** | 둘 다 신호 없음. 아임웹 SSR 이라 파싱은 제일 쉽다(각 24종·13종). **두 곳이 같은 CMS 라 파서를 공유할 수 있다**(화이트리에·못난이꽈배기·노티드까지 5곳) | 24 / 13 | 각 2 |
| 7 | **패션5** | 신호 **확인 못 함**. SPC 프리미엄 디저트 라인이라 인지도는 높고 Cafe24 SSR 이라 수집은 쉽다. **붙이기 전에 `icon_` 이미지가 상품 배지인지부터 확인해라**(파리크라상 전례) | 카테고리당 미확인 | 미확인 |

### 추천에 넣지 않은 이유

- **송사부고로케** — robots 에 손으로 주석까지 달아 AI 봇 10종을 막는다. 앤티앤스와 같은 건이다. 🔴
- **호밀호두** — robots 403. 순위 문제가 아니라 **붙이면 안 된다.**
- **화이트리에 · 못난이꽈배기** — 수집은 쉬우나 신호가 없고 인지도가 낮다. 아임웹 파서를 만들면
  한계비용이 거의 0이므로 **올드페리도넛·아이엠도넛을 붙일 때 같이 얹는 것**이 합리적이다.
- **코코호도** — 가맹점 167개로 이번 조사 대상 중 **가장 크다.** 그런데 실제 사이트가
  `cocohodo.twomos.com` SPA 라 `/products` 가 9KB 껍데기다. **API 를 못 찾았다**(예산 소진).
  API 만 풀리면 순위가 크게 오를 수 있다 — **재조사 1순위다.**
- **신라명과 · 복호두** — robots 만 받고 끝났다. 신라명과는 Cafe24 라 수집은 쉬울 가능성이 높다.
- **도레도레** — WordPress 4.3.34 에 콘텐츠가 2015년대다. robots 도 못 받았다.
- **리치몬드 · 롤링핀 · 빵장수단팥빵 · 메종드조에 · 투썸 케이크** — 사이트가 없거나 막혀 있다(§5).

## 9. 어댑터를 쓸 사람에게 넘기는 주의사항

1. **나폴레옹과자점 `day8until_newarrival` 의 의미를 확정하기 전에 `released_at` 에 넣지 마라.**
   필드명만으로는 시작일/종료일/기간이 구분되지 않는다. 며칠 관찰해서 값이 갱신되는 방향을 보고
   결정해라. 확정 전에는 `is_new` 플래그로만 써라.
2. **나폴레옹 페이지네이션이 미해결이다.** `?page=2` 가 무시되고 응답 `page` 가 계속 `1` 이다.
   `total: 354`, `pageSize: 36` 이라 현재는 **10%만 접근 가능**하다. 어댑터를 붙이려면
   이 문제를 먼저 풀어야 한다.
3. **아임웹 브랜드 5곳의 약관은 `/?mode=policy` 이고 robots 금지 경로다.**
   `can_fetch()` 는 True 를 주지만 **실제로는 위반**이다(§4). 받지 마라.
4. **노티드와 GFFG 는 TLS 인증서가 만료됐다**(각각 2026-09-06, 2026-07-03).
   `verify=False` 를 쓰지 말고 `http://` 로 붙어라. `CRAWLING-POLICY.md` §6-1 그대로다.
   어댑터 모듈 docstring 에 만료일을 적어라.
5. **브레댄코 media API 날짜는 `uploaded_at` 이다.** 파일명 `YYMMDD_` 도 마찬가지다.
   `released_at` 으로 승격시키지 마라.
6. **노티드 HTML 의 `NEW` 문자열을 세지 마라.** 41회 중 37회가 주석 안에 있다.
   배지 판정은 문자열 카운트가 아니라 **주석 밖 DOM 노드**로 해라.
7. **아임웹 5곳(노티드·올드페리도넛·아이엠도넛·화이트리에·못난이꽈배기)은 같은 CMS 다.**
   robots 가 바이트 단위로 같고 구조도 같다. **파서 하나를 공유할 여지가 크다.**
   1차의 요거프레소·명랑핫도그 관계와 같다.
8. **삼송빵집은 nav 가 전부 `javascript:GoPage(code)` 다.** 링크 추출기로는 경로가 안 나온다.
   홈 HTML 안의 `function GoPage` 매핑을 읽어서 `/doc/menu1~5.php` 를 직접 써라(§2-6에 전체 매핑).
9. **홍루이젠은 `Crawl-delay: 10` 이다.** 우리 기본 간격(2초)보다 훨씬 길다. 반드시 지켜라.
10. **`BRANDS` 레지스트리 세부분류.** 1차가 남긴 숙제가 그대로다. `베이커리`(파리바게뜨)와
    `디저트`(배스킨라빈스·던킨)가 이미 갈려 있는데, 여기 후보는 **케이크 전문**(나폴레옹·패션5·신라명과)과
    **도넛**(노티드·올드페리도넛·아이엠도넛)이 또 다르다. `base.py` 의 `BRANDS` 한 곳에서 정하는
    원칙은 유지해라.

## 10. 확인 못 한 것

- **나폴레옹 `day8until_newarrival` 의 정확한 의미** — §2-1, 주의사항 1번.
- **나폴레옹 상품 페이지네이션** — `?page=2` 가 안 먹는다. 나머지 318건에 접근하지 못했다.
- **나폴레옹 `/api/` 아래 엔드포인트** — robots 가 `/api/test` 를 따로 막는 것으로 보아 존재하지만 못 찾았다.
- **브레댄코 상품이 실제로 렌더되는 위치** — `/product/new-product/new-bread/` 본문에
  2024년 이후 상품 이미지가 하나도 없었다. 전체 상품 수도 모른다.
- **패션5 `icon_*.png` 가 상품 배지인지** — 파리크라상에서 같은 것이 장바구니 버튼이었던 전례 때문에
  단정하지 않았다.
- **코코호도 SPA 의 데이터 API** — `cocohodo.twomos.com/products` 가 9KB 껍데기다.
  가맹점 167개로 이번 조사 최대 규모라 **재조사 가치가 가장 높다.**
- **도레도레 robots.txt** — `doredore.co.kr` 과 `www.doredore.co.kr` 둘 다 robots 요청에
  서버가 연결을 끊었다(`RemoteProtocolError`). 홈은 정상적으로 열린다. 원인 불명.
- **삼송빵집 `/doc/menu2~5.php` 와 공지·이벤트 게시판(그누보드)** — 예산상 menu1 만 봤다.
  게시판에 날짜가 있을 가능성이 있다.
- **신라명과 · 복호두** — robots 만 받았다. 상품 페이지 구조를 못 봤다.
- **로띠번(`rotiboy.co.kr`) 443 ConnectTimeout · 따삐오(`tapio.co.kr`) TLS 호스트명 불일치** —
  1차의 아티제·옥루몽·밀크카우와 같은 증상이다. 우리 쪽 경로 문제인지 사이트 문제인지 구분 못 함.
- **오뗄두스 · 곰곰베이커리 공식 도메인** — 특정 실패. 오뗄두스는 SNS 채널만 확인됐고,
  곰곰베이커리는 공정위 `제과제빵` 목록에도 없다. **브랜드가 실재하는 프랜차이즈인지부터 확인이 필요하다.**
- **공정위 `제과제빵` 10개 브랜드의 공식 URL** — §6. 유추 도메인이 전부 DNS 무응답이었다.
- **이용약관 전반** — 이번 조사에서 약관 원문을 확보한 브랜드가 **0곳**이다.
  아임웹 5곳은 robots 금지라 못 받았고, 나머지는 요청 예산이 상품 구조 확인에 먼저 쓰였다.
  **붙일 브랜드는 반드시 따로 확인해야 한다.**

> 요청 예산 메모: 총 **60 HTTP 요청** / 27개 호스트. 브랜드당 최대는 **5회**이고
> (브레댄코·나폴레옹과자점·홍루이젠·코코호도·도레도레) 상한을 넘긴 브랜드는 없다.
> 도레도레는 5회 중 4회가 연결 실패였다. DNS 79건·TLS 24건은 HTTP 요청이 아니라 부하에 포함하지 않았다.
