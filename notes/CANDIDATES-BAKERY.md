# 브랜드 후보 조사 — 베이커리 · 디저트 · 아이스크림

`BRAND-CANDIDATES.md` 와 같은 형식이다. **어댑터는 없다.** 이 문서는 조사 결과일 뿐이다.

- 조사일: **2026-09-30**
- 조사 방법: 브랜드당 HTTP 5회 이내, 요청 간 2.5초, `collectors/base.client()` (UA `sinsang-note/1.0`)
- 조사 범위: robots.txt + 홈 + 메뉴/신메뉴 페이지 구조 + 이용약관. **전체 메뉴를 긁지 않았다.**
- robots 는 전부 `urllib.robotparser.can_fetch("*", …)` 로 실측했다. 눈으로 읽고 판정한 건 없다.
- 추측으로 채운 칸은 없다. 못 본 것은 "확인 못 함"이라고 적었다.

**이미 처리된 배스킨라빈스·던킨·설빙은 제외했다.** 다른 에이전트가 맡은 한식·분식·일식·중식·카페·주점은 건드리지 않았다.

조사한 브랜드 **21곳**. 수집 가능 8 / 불가·금지 4 / 도메인이나 사이트를 못 찾음 9.

## 3. 근거 (실측 조각)

추측과 구분하기 위해 실제로 받은 것을 남긴다.

### 파리바게뜨 — 이 조사의 최대 수확

robots 는 `/wp-admin/` 만 막는다. **WordPress REST API 가 열려 있고 `date` 필드가 그대로 온다.**

```
GET https://www.paris.co.kr/wp-json/wp/v2/product?per_page=10&_fields=id,date,slug,title
→ 200, X-WP-Total: 535, X-WP-TotalPages: 54
```
```json
[{"id":185511,"date":"2026-09-30T02:00:28","modified":"2026-09-30T02:00:28",
  "slug":"mozzarella-cheese-sticks-2","title":{"rendered":"모짜렐라 치즈봉"},
  "product_category":[30,31], …}]
```

`can_fetch("*", "https://www.paris.co.kr/wp-json/wp/v2/product")` → **True**.

WP 기본 정렬이 `date` 내림차순이라 **1요청이면 최신 등록 상품이 날짜와 함께 온다.**
전체를 받아도 `per_page=100` 기준 6요청이다. HTML 목록(`/products/`)에는 NEW 배지가 없다 —
날짜 신호는 오직 API 에만 있다.

**⚠️ 이삭토스트 `prdcode` 와 같은 유보가 필요하다.** `date` 는 워드프레스 글의 **발행일**이지
브랜드가 선언한 출시일이 아니다. 홈페이지 개편 때 일괄 재발행되면 메가MGC커피·노브랜드버거와
같은 날짜 뭉침이 생긴다. 어댑터를 붙이기 전에 `date` 분포를 먼저 실측해서
한 날짜에 수십 건이 몰려 있지 않은지 확인하고, 몰려 있으면 `uploaded_at` 까지만 써라.

**⚠️ 응답에 UTF-8 BOM 이 붙는다.** `json.loads(r.text)` 가 그대로 터진다:
```
json.decoder.JSONDecodeError: Unexpected UTF-8 BOM (decode using utf-8-sig)
```
`r.content.decode("utf-8-sig")` 로 받거나 `json.loads(r.text.lstrip("﻿"))` 로 풀어야 한다.

### 요거프레소 — 출시 연월이 텍스트로 붙어 있다

`/menu/menu-new.html` 한 페이지가 신메뉴 아카이브다. 렌더 텍스트:

> 2026년 7월 유자레몬 샤베트 / 2026년 7월 신메뉴 레트로 미숫가루 / 2026년 6월 신메뉴 아이스컵빙수 시리즈 /
> 2026년 6월 신메뉴 레트로밀크커피 / 2026년 4월 신메뉴 말차크림라떼 시리즈 / … / 2022년 6월 신메뉴

2022년까지 거슬러 쌓여 있다. 이미지 경로가 연월을 한 번 더 확인해 준다:

```
/upload/new_menu/202607/1783296680_m0118201_20260706091120.png
/upload/new_menu/202605/1779242895_m0164267_20260520110815.png
```

폴더가 `YYYYMM`, 파일명 꼬리가 `YYYYMMDDHHMMSS` 다. **텍스트 라벨과 경로가 서로를 교차 검증한다.**
이 조사에서 `released_at` 을 채울 수 있는 두 곳 중 하나다(다른 하나가 파리바게뜨).

**⚠️ 한계 두 가지.**
1. 정밀도가 **월 단위**다. `released_at` 에 `2026-07-01` 같은 임의의 일자를 박지 마라.
   파일명 타임스탬프를 쓰면 일자까지 나오지만 그건 업로드 시각이라 `uploaded_at` 이다.
2. 항목이 **개별 SKU 가 아니라 시리즈 단위**다("아이스컵빙수 시리즈", "쫀득베이글 3종").
   그리고 "신메뉴" 말고 **"리뉴얼"·"한정메뉴"·"NEW 토핑"** 라벨이 섞여 있다.
   `is_new` 를 줄 때 라벨 문자열을 그대로 보고 판정해야 한다.

### 명랑핫도그 — NEW 가 메뉴 대분류다

nav 가 `메뉴 > NEW / 핫도그 / 떡볶이 / 명랑's 치즈스틱 / 세트 / 사이드 / 소스` 이고,
NEW 가 전용 페이지를 갖는다. `/menu/new.html` → `/menu/new` 로 리다이렉트되며 SSR 이다.

> 메뉴 NEW 핫도그 떡볶이 … 빠삭하게 한 입! 100% 자연치즈의 짭짤함! 명랑's 치즈스틱(오리지널) /
> 매콤짭짤한 소스로 진짜 미국의 맛! 명랑's 치즈스틱(내슈빌) / … 쫄깃한 라이스페이퍼 속 모짜렐라 치즈가
> 풍성하게 있는 떡볶이 럭키 모짜라이스롤 떡볶이 / 명랑's 더블치즈스틱(허니 치폴레) …

설명문까지 한 페이지에 온다. 날짜는 없다. 전체 메뉴는 `/menu/menu.html?depth1=4,5,6,7,8,14` 6개다.

**⚠️ 캐러셀이라 같은 항목이 여러 번 나온다.** 위 렌더에서 "럭키떡볶이&고마통모짜 세트"가 8번 반복됐다.
DOM 을 그대로 훑으면 중복이 들어온다. `Item.key` 가 잡아주긴 하지만 어댑터에서 먼저 걸러라.

요거프레소와 **같은 CMS**다(`../menu/` 상대경로, `본문내용 바로가기/헤더 바로가기/푸터 바로가기` 스킵링크,
`/policy/term.html`). 한쪽 파서가 다른 쪽에 거의 그대로 먹힐 가능성이 높다.

### 요아정 — 수집은 제일 쉬운데 신호가 없다

`/bbs/content.php?co_id=menustore` **1요청에 2.1MB**, 전 메뉴가 SSR 로 들어있다.
그런데 이건 상품 목록이 아니라 **조합 구성기**다.

> STEP 1. 메뉴 선택 … 허니 무화과 / 몽땅 무화과가 달콤하구마 / 호박인절미 / 그릭의 정석 /
> 요아정 수빈 PICK / 요아정 연준 PICK / … / [저당 복숭아] 리틀어피치 스윗 그릭보바 복숭아 …
> STEP 2. 인분 선택 1인분 2인분 3인분 4인분 / 요거트아이스크림 150g 300g 450g 600g …

`NEW`·`신제품`·`신메뉴`·`출시` 문자열이 **0회**다. 콜라보 메뉴(아이돌 PICK)가 사실상 신제품이지만
그걸 알려주는 표시가 없다. diff 로만 판정하게 된다.

푸터로 정본 확인: **주식회사 요아정 / 대표자 박현희 / 사업자번호 696-86-02195**.

### 뚜레쥬르 — 우리를 명시적으로 막는다

```
## disallow all other bots
User-agent: *
Disallow: /

## Google
User-agent: Googlebot
Allow: /$
Allow: /product
…
```
`can_fetch("*", "https://www.tlj.co.kr/product/")` → **False**. `/` 도 False 다.
사이트에 `제품 > NEW` 카테고리가 있지만 **붙이면 안 된다.** 빕스·롯데리아와 같은 건이다.

### 파리바게뜨 이용약관 — 회원 약관이고 영리목적 한정이다

`/terms/` → `/terms-of-use/`. 제목은 "이용약관"인데 실제로는 **해피포인트카드 회원 약관**이고
당사자가 **주식회사 에스피씨클라우드**다. 제22조(저작권의 귀속 및 이용제한) ②항:

> 회원은 당사 홈페이지를 이용함으로써 얻은 정보를 당사의 사전 승낙없이 복제, 송신, 출판, 배포, 방송
> 기타 방법에 의하여 영리목적으로 이용하거나 제 3자에게 이용하게 하여서는 안됩니다.

크롤링·스크래핑·매크로 같은 단어는 **없다.** 이마트24 제8조⑧ 같은 명시적 금지가 아니다.
다만 (가) 주어가 "회원"이고 (나) "영리목적"으로 한정된다는 점에서
`CRAWLING-POLICY.md` §4 의 **이디야(회원 약관, 적용 범위 애매) + 스타벅스(재배포 금지) 중간**에 해당한다.
🔴 가 아니라 🟠 다. **회원가입은 하지 마라** — 가입하면 이 약관이 계약으로 구속력을 갖는다.

### 요거프레소 · 명랑핫도그 약관 — 브랜드와 무관한 붙여넣기다

둘 다 `/policy/term.html` 이고 **본문이 완전히 동일하다**. 그리고 내용이 도넛도 핫도그도 아닌
**도메인 등록 서비스 약관**이다:

> 제 8 조 (사이트의 의무) ① 사이트는 회원에게 각 호의 서비스를 제공합니다.
> 가. 신규서비스와 도메인 정보에 대한 뉴스레터 발송 나. **추가 도메인 등록시 개인정보 자동 입력**
> 다. **도메인 등록, 관리를 위한 각종 부가서비스**

홈페이지 제작사가 템플릿을 그대로 넣어둔 것이다. 그 안의 제9조 ①나 항이 유일하게 관련 있다:

> 회원은 … 서비스에서 얻은 정보를 사이트의 사전승낙 없이 회원의 이용 이외의 목적으로 복제하거나
> 이를 변경, 출판 및 방송 등에 사용하거나 타인에게 제공하는 행위

크롤링 명시 금지는 없고, 주어는 "회원"이다. **이 약관이 그 브랜드의 의사를 반영한다고 보기 어렵다**는
점이 오히려 판단을 어렵게 한다. 🟡 로 둔다.

### 앤티앤스 robots — 규칙상 허용인데 의도는 정반대다

`User-agent: *` 규칙이 **아예 없고**, 대신 특정 봇 수십 종을 하나씩 `Disallow: /` 한다:

```
User-agent: GPTBot      / Disallow: /
User-agent: ChatGPT-User/ Disallow: /
User-agent: CCBot       / Disallow: /
User-agent: ClaudeBot   / Disallow: /
User-agent: Amazonbot   / Disallow: /
User-agent: meta-externalagent / Disallow: /
… (AhrefsBot, semrushbot, PetalBot, facebookexternalhit 등 30종 이상)
```

`can_fetch("*", "https://www.auntieannes.co.kr/")` → **True**. 우리 UA 가 목록에 없으니 규칙상 허용이다.
하지만 **"AI·데이터 수집 봇은 다 막겠다"는 의사표시가 이보다 분명할 수 없다.**
굽네치킨 `/menu/new.jsp` 건과 같은 종류인데 그보다 훨씬 강하다. 붙이지 않는 쪽을 권한다.
(어차피 홈이 8KB 스플래시라 메뉴 페이지가 어디인지도 아직 모른다.)

## 6. 추천 순위

기준 순서는 **(1) 신제품 신호 → (2) 수집 난이도 → (3) 브랜드 관심도** 다.

| # | 브랜드 | 근거 | 상품 수 | 예상 요청 수 |
|---|---|---|---|---|
| 1 | **파리바게뜨** | 이 조사에서 **유일하게 상품별 날짜를 API 로 직접 준다.** 기본 정렬이 날짜 내림차순이라 **1요청이면 최신 신제품이 나온다.** 국내 베이커리 1위라 관심도도 최상 | 535 | **1** (신제품만) / 6 (전체) |
| 2 | **요거프레소** | 신메뉴 전용 페이지에 **출시 연월이 텍스트로** 붙고 이미지 경로(`/upload/new_menu/202607/`)가 교차 검증해 준다. 2요청이면 끝 | 신메뉴 ~45항목 | **1** (신메뉴) / 7 (전체) |
| 3 | **명랑핫도그** | NEW 가 메뉴 대분류라 **URL 로 분리돼 있다**(`/menu/new`). 파싱 실패 위험이 가장 낮은 형태. 날짜는 없음 | NEW ~8 / 전체 미확인 | **1** (NEW) / 7 (전체) |
| 4 | **요아정** | 신호는 **없다.** 그래도 4위인 건 **1요청에 전체가 오고** 요거트아이스크림 카테고리 관심도가 지금 제일 높기 때문. 합류 첫날 신제품 0건은 감수해야 한다 | 전체 1페이지 | **1** |

### 추천에 넣지 않은 이유

- **뚜레쥬르** — 관심도로만 보면 파리바게뜨 다음이다. 하지만 robots 가 우리를 명시적으로 막는다.
  순위 문제가 아니라 **붙이면 안 된다.**
- **앤티앤스** — 규칙상 can_fetch 는 True 지만 robots 가 AI·데이터 봇 30종 이상을 하나씩 막는다.
  의사표시가 분명하다. 그리고 메뉴 페이지가 어디인지도 모른다.
- **스트릿츄러스** — `New Menu` 전용 탭이 있어서 기대했는데 **갤러리에 상품이 0건**이다.
  `cate=menu1`(츄러스)도 `cate=menu2`(New Menu)도 이미지·상품명이 하나도 안 나온다.
  껍데기만 있는 게시판이라 붙일 게 없다.
- **크리스피크림** — 도넛 카테고리 관심도 1순위인데 **사이트가 접근 자체가 안 된다**(HTTPS 인증서 만료,
  HTTP 전 경로 403). 다른 공식 경로를 못 찾았다.
- **성심당** — 직영이라 이 서비스의 "프랜차이즈" 정의에 안 맞는다. PRODUCT 페이지도 확인 못 했다.
- **노티드 · 런던베이글뮤지엄 · 백미당 · 나뚜루 · 슈퍼두퍼** — 공식 도메인을 못 찾았다. §5 참고.
- **하겐다즈** — `haagen-dazs.global` 로 리다이렉트되고 거기엔 매장 찾기만 있다. 한국 메뉴가 없다.

## 7. 신제품 신호가 확실한 브랜드 (요약)

붙이는 날부터 신제품을 내놓을 수 있는 곳이다. **세 곳뿐이다.**

| 신호 종류 | 브랜드 |
|---|---|
| **날짜 (`released_at` 후보)** | 파리바게뜨 (WP REST `date`, 일자까지) · 요거프레소 (텍스트 라벨, **월 단위**) |
| **신제품 전용 페이지·카테고리** | 요거프레소 (`/menu/menu-new.html`) · 명랑핫도그 (`/menu/new`) |
| **NEW 배지 (`is_new`)** | **없음** — 이 카테고리에서 상품 카드에 NEW 배지를 단 브랜드를 하나도 못 찾았다 |
| 없음 | 요아정, 랜디스도넛, 이성당 |
| 확인 못 함 | 파리크라상, 성심당, 앤티앤스 |

## 8. 어댑터를 쓸 사람에게 넘기는 주의사항

1. **파리바게뜨 API 응답에 UTF-8 BOM 이 붙는다.** `json.loads(r.text)` 가 `Unexpected UTF-8 BOM` 으로
   그대로 터진다. `r.content.decode("utf-8-sig")` 를 써라. `httpx` 가 알아서 벗겨주지 않는다.
2. **파리바게뜨 `date` 를 `released_at` 에 넣기 전에 분포부터 봐라.** 워드프레스 발행일이라
   사이트 개편 때 일괄 재발행되면 메가MGC커피(2024-06 에 81건)·노브랜드버거(2025-05-07 에 24건)와
   같은 뭉침이 생긴다. 한 날짜에 수십 건이 몰려 있으면 `uploaded_at` 까지만 써라.
3. **요거프레소 날짜는 월 단위다.** "2026년 7월"에서 `2026-07-01` 을 만들어내지 마라.
   그리고 항목이 SKU 가 아니라 **시리즈** 단위이고 "신메뉴"·"리뉴얼"·"한정메뉴"·"NEW 토핑"이 섞여 있다.
   라벨 문자열을 그대로 읽고 `is_new` 를 판정해라.
4. **명랑핫도그는 캐러셀 중복이 심하다.** 같은 세트가 8번 반복돼 나온다. 어댑터에서 먼저 중복을 접어라.
5. **요거프레소와 명랑핫도그는 같은 CMS 다.** 같은 스킵링크 구조, 같은 `../menu/` 상대경로,
   같은 `/policy/term.html` 약관. 한쪽 파서를 다른 쪽에 재사용할 여지가 크다.
6. **랜디스도넛은 EUC-KR 인데 헤더에 charset 이 없다.** `Content-Type: text/html` 뿐이라
   `r.text` 가 깨진다. `r.content.decode("euc-kr")` 로 직접 풀어야 한다.
   게다가 HTTPS 가 **자체서명 인증서**라 http 로만 붙는다. 평문 통신을 받아들일지 판단이 필요하다.
7. **스트릿츄러스도 HTTPS 가 깨져 있다**(호스트명 불일치 — 인증서가 `streetchurros.com` 용이 아니다).
   어차피 수집할 게 없어서 문제는 안 되지만, 이 카테고리에 HTTPS 파손 사이트가 둘이다.
8. **`BRANDS` 레지스트리에 세부분류를 먼저 등록해야 한다.** 배스킨라빈스·던킨이 이미 `디저트` 로 들어가
   있는데, 베이커리(파리바게뜨·파리크라상)는 그것과 구분할지 정해야 한다. 요거프레소는 카페인지
   디저트인지도 애매하다. `base.py` 의 `BRANDS` 한 곳에서 정하는 원칙은 유지해라.
9. **파리바게뜨 약관은 🟠 다.** 이마트24·도미노·폴바셋처럼 수집을 접을 정도의 명시적 금지는 아니지만
   "영리목적 복제·배포 금지"가 있다. 스타벅스와 같은 취급(제목 + 원문 링크 위주)이 안전하다.
   **어느 경우에도 회원가입은 하지 마라.**

## 9. 확인 못 한 것

- **배달의민족 계열 디저트 브랜드** — 어떤 브랜드를 가리키는지 특정하지 못했다. 브랜드명이 필요하다.
- **파리크라상 상품 카드의 NEW 배지 유무** — 목록 HTML 에 `NEW` 문자열이 11회 나오지만
  그게 상품 배지인지 내비게이션·스크립트 문구인지 5요청 안에 가려내지 못했다.
  `list5.html` 의 `icon_` 이미지는 확인해 보니 **장바구니 버튼**이었다(`selectOptionCommon(…,'basket')`).
- **파리크라상 전체 카테고리 수와 상품 수** — `cate_no=63` 한 곳이 174건인 것만 봤다.
- **성심당 PRODUCT 페이지 구조** — robots 의 `Sitemap: /sitemap.php` 를 받았더니
  **PHP 가 실행되지 않고 소스가 그대로 나왔다**(`$g5[write_prefix]`, `sql_query(...)`).
  이걸로 gnuboard5 라는 것과 `/bbs/board.php?bo_table=…` 구조라는 건 알았지만
  실제 상품 게시판 `bo_table` 값은 모른다. 서버 설정 사고로 보이며, 우리가 파고들 대상은 아니다.
- **앤티앤스 실제 브랜드 사이트 URL** — 홈이 "브랜드 홈페이지 / 창업 홈페이지" 두 링크뿐인 스플래시다.
- **이성당 상품 목록** — 홈이 모바일 안내 문구만 렌더해서 카테고리 구조를 못 봤다.
- **아티제 · 옥루몽 · 밀크카우** — 443 ConnectTimeout. 우리 쪽 경로 문제인지 사이트 문제인지 구분 못 함.
- **랜디스도넛 `c=2…5` 상품 수** — `c=1`(BEST) 6건만 봤다.
- **명랑핫도그 전체 메뉴 상품 수** — NEW 카테고리만 봤다.
- **요아정 · 파리크라상 · 랜디스도넛 · 이성당 · 성심당 · 앤티앤스 이용약관** — 요청 예산상 못 봤다.
  붙일 브랜드는 반드시 따로 확인해야 한다.

> 요청 예산 메모: 파리바게뜨만 **7요청**을 썼다(robots·홈·`/products/`·API 2회·약관 2회).
> 1순위 추천이고 약관 확인이 조사 항목이라 초과를 감수했다. 나머지는 전부 5회 이내다.
