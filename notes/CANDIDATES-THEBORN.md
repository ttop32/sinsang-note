## 2. 신상 판정 근거 — 무엇을 믿었고 무엇을 안 믿었나

### 2-1. 믿은 것

| 신호 | 어디 | 왜 믿나 |
|---|---|---|
| 보도자료 '출시' 기사 | theborn.co.kr 뉴스 | 브랜드가 직접 "출시한다"고 낸 글이다. 오뚜기·오리온·GS25 와 같은 근거 |
| `event_type_nm = "신제품"` | KFC | **KFC 가 레코드에 적어 둔 유형**이다. 우리가 배지를 해석한 게 아니다 |
| RSS `pubDate` | 한신포차 | 메뉴 글이 올라온 날. 52/52 조인 + 51/52 이미지 경로 일치로 교차검증 |

### 2-2. 가짜로 판명돼 버린 것 — **여기가 이 조사의 핵심이다**

| 가짜 신호 | 어디서 걸렸나 | 반증 |
|---|---|---|
| **이미지 HTTP `Last-Modified`** | 역전우동 등 | `/uploads/2025/12/` 파일이 2026-02-27, `/uploads/2026/07/` 파일이 **2026-10-01**, `/uploads/2018/04/` 파일이 2025-03-27. 서버 mtime 이 재저장으로 덮인다 |
| **`/wp-content/uploads/YYYY/MM/` 경로** | 전 브랜드 | 연·월뿐이고 '일'이 없다. 1일로 채우면 지어낸 값이다(`cafe_paikdabang.py` 선례) |
| **WP REST `media.date`** | 역전우동 | `x-wp-total: 349` 인데 실제 31건만 오고 `page=5` 는 400. 31건 중 6건이 경로 연월과 불일치. 현행 메뉴 이미지(2026/10)는 응답에 없다 |
| **WP REST `media.date`** | 미정국수0410 | 134건은 받아지는데, **2026-01-15 15:38~15:58 20분 사이에 2018년 간판 메뉴 20여 장이 한꺼번에** 등록돼 있다. 25건 중 24건이 경로 연월과 어긋난다 |
| **`post_date`** | 백스비어 | 40건 중 34건이 2025-09-28~29 **10분 간격 격자**. CMS 일괄 이관 흔적. 2018년 상품 '순살후라이드치킨'의 post_date 가 2025-09-29 다 |
| **`new` 문자열** | 한신포차 | `<title>한신메뉴</title>` 와 네비 링크 — **'한' + '신메뉴'** 부분일치 3건 |
| **`new` 문자열** | 백스비어 | `<!-- NEW SLIDE -->` swiper 주석 + SVG `enable-background:new` 36건 |
| **`new` 문자열** | 성성식당 | 이미지 **파일명** `05_이태리찜닭_new.jpg` 등 4건. 2017/06 업로드분이고 카드 마크업은 다른 상품과 동일 |
| **`custom_is_best_menu`** | 백스비어 | BEST 지 NEW 가 아니다. True 5건에 2024/11 묵은 상품이 들어 있다 |
| **`item-new` 배지** | 새마을식당 **배달 탭** | `menu2.php` 의 `item-new` 상품 이미지 epoch 가 **1680071654 = 2023-03-29**. 3년 반째 NEW 로 박혀 있다 |

> 세븐일레븐 '신상품' 탭 사고와 같은 종류를 **9건** 잡았다. 전부 "문자열이 있다 ≠ 신호다"였다.

### 2-3. 진짜지만 안 쓴 것

- **새마을식당 홀 메뉴 `li.item-new`** — 진짜다. `/_css/common.css` 가 `li.item-new:after { background-image: url(../_imgs/icon_new.png) }` 로 실제 아이콘을 그리고 그 PNG 가 200(4,509 bytes)이다.
  **그런데 안 썼다.** 지금 이 배지가 붙은 건 **열탄대창불고기 1건뿐**이고, 그건 `theborn.py` 가 **2026-08-25 라는 진짜 날짜와 함께** 이미 가져온다.
  새마을식당용 어댑터를 따로 만들면 ① 같은 브랜드가 두 어댑터에 걸려 **키가 두 줄로 들어가고**(collect 는 어댑터 사이 중복을 안 걸러준다) ② 날짜가 없어져 합류 첫날 `baseline` 으로 묻힌다. 측정해 보니 **얻는 게 0이고 잃는 게 날짜**라 보도자료 쪽에 뒀다.
- **본문 `📌출시일 : 9/3(목)`** — 롤링파스타 2026-09-10 기사가 게시일보다 7일 이른 실제 출시일을 적어 뒀다. 창 안 6건 중 1건에만 있고 **연도가 없다**. 연도를 우리가 채우면 지어낸 값이라 안 썼다.
- **돌배기집 REST media `date`** — 18/18 조인되고 18/18 경로 연월이 일치한다(역전우동이 실패한 그 대조를 통과). 그래도 이건 **이미지 업로드 시각**이고 8/18 이 2024-10-29 사이트 개편일에 몰려 있다. 신제품 배지가 없어 결국 diff 의존이라 등록하지 않았다.

## 3. 제목 → 상품명 추출 (theborn.py §3)

211건 전수에 돌려 **22개 기사 · 32개 상품**을 집었고 **32건 전부 눈으로 대조했다(오집 0)**.

- `N종` 이 있으면 `N종(A, B, …)` 괄호 목록을 찾고 **쉼표로 쪼갠 개수가 N 과 같을 때만** 쓴다.
  이 개수 일치가 제일 센 자기검증이다 — 빽보이피자 카카오프렌즈 기사의 `3종(▲피자박스 춘식 …)` 굿즈 목록이 N=2 라서 자동 탈락한다.
- 괄호 목록이 없으면 **본문 따옴표가 정확히 N개일 때만**. 전수에서 이 폴백이 걸린 건 1건(빽보이피자 2025-12-17)이고 3개 전부 맞았다. 나머지 기사는 따옴표가 5~12개라 불일치로 탈락한다.
- `N종` 이 없으면 제목의 마지막 따옴표 안.

### ⚠️ '협업'·'콜라보'를 금지어로 두면 안 된다

처음에 제목 금지어로 넣었다가 **역전우동 신메뉴 3건이 통째로 날아갔다**
(열탄제육덮밥 · 구운어묵튀김우동 · 간장양념구이 덮밥). 더본은 콜라보 신메뉴를 자주 낸다.
GS25 선례대로 **위치**로 가른다 — 따옴표 **뒤**에 협업어가 오면 그 따옴표 안은 제휴 상대다.

```
"역전우동, 장호준 셰프와 두번째 협업 '구운어묵튀김우동' 출시"   → 뒤가 '출시'   → 상품 ✅
"빽보이피자, 피자업계 최초 '카카오프렌즈'와 협업 신메뉴 출시"    → 뒤가 '와 협업' → 버림 ✅
```

## 6. 미확인으로 남긴 것

- KFC 이용약관 본문 — SPA 셸이라 초기 HTML 에 없다. 브라우저 없이는 못 읽었다.
- KFC 지난 신제품 — `/promotion/newMenu` 는 **판매 중인 것만** 준다(현재 1건). 종료분 목록이 없고, `event_index` 를 훑는 건 스캐닝이라 안 했다.
- 한신포차 `pubDate` 가 '메뉴판 등록일'인지 '매장 실제 출시일'인지 — 사이트만으로는 구분 불가. 그래서 `released_at` 이 아니라 `uploaded_at` 에 넣었다.
- 글로벌 2개(인생설렁탕-copy, 연돈볼카츠-copy)의 신호·날짜 — 해외 라인이라 안 팠다.
- 각 브랜드의 실제 매장 수·폐점 여부 — 매장 DB 가 robots 로 막혀 있다.
