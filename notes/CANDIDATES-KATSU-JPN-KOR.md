`notes/CANDIDATES-KOREAN.md` 와 같은 형식이다. 다만 이 문서는 **조사 결과이자 작업 기록**이다 —
수집 가능으로 판정한 곳은 어댑터까지 만들어 `base.BRANDS`·`SITES`·`collect.ADAPTERS` 에 등록했다.

- 조사일: **2026-10-02**
- 순위 근거: 공정거래위원회 **2025년도 정보공개서** (가맹점 수는 **2024년 말** 기준)
- 조사 방법: 브랜드별 HTTP 요청 간 1~2.5초, `collectors/base.client()` (UA `sinsang-note/1.0`)
- 추측으로 채운 칸은 없다. 못 본 것은 "확인 못 함"이라고 적었다.
- **이미 등록돼 있던 브랜드는 건드리지 않았다**: 본아이에프 8브랜드(본죽·본죽&비빔밥·본도시락·

- **다른 담당 영역은 제외했다**: 치킨, 중식, 김밥·떡볶이·분식·우동, 더본코리아 전 브랜드, KFC, CU.

## 1. 순위를 어떻게 뽑았나

### 공정위에서 된 것 / 안 된 것

`notes/FRANCHISE-MASTER.md` §2 가 적어둔 그대로다. 2026-10-02 에 다시 실측해 확인했다.

**브랜드 전수는 GET 한 번에 나온다.** 로그인·JS 불필요.

```
GET franchise.ftc.go.kr/mnu/00013/program/userRqst/list.do
    ?selUpjong=21&selIndus=<중분류>&pageUnit=9000&pageIndex=1
```

이번 조사에서 받은 행수(2026-10-02): 한식 3,776 / 분식 501 / 중식 313 / **일식 515** /
서양식 285 / 기타 외국식 204 / 패스트푸드 147 / 기타 외식 1,143.
(FRANCHISE-MASTER 작성 시점보다 한식 +3, 기타 외식 +1 늘었다. 매일 신규 등록이 붙는다.)

**브랜드별 가맹점 수는 여전히 공개 화면에 없다.** 상세(`view.do`)는 `class="authCtrl"` 이라
로그인이 필요하고, 가맹희망플러스는 업종 단위 합계만 준다. 공공데이터포털 오픈API
(`15143710` 브랜드별 가맹점/직영점 수)에 정확히 그 값이 있지만 **활용신청·서비스키가 전제**라
이번에도 못 썼다. 사람이 신청해 두면 다음 조사부터 이 문서의 가맹점 수 칸을 자동으로 채울 수 있다.

### 그래서 2순위 소스를 썼다

가맹점 수는 [프차몰 업종별 순위](https://fchamall.com/franchise) 에서 받았다.
공정위 2025년도 정보공개서를 그대로 집계해 내는 곳이고, FRANCHISE-MASTER §3 이
공정위 보도자료 공식 TOP5 와 대조해 치킨·한식·커피·제과제빵·피자 5개 업종이 일치함을
이미 확인해 뒀다.

**이번에 새로 알아낸 것: `?page=N` 으로 TOP30 너머까지 전부 받을 수 있다.**
FRANCHISE-MASTER 는 업종별 TOP30 에서 멈췄는데, 그 제약이 없어졌다. 받은 전수:
일식 191 / 서양식 92 / 패스트푸드 51 / 기타 외식 475 / 분식 201 / 한식 1,207 / 기타 외국식 84.
(가맹점 5개 미만 브랜드는 프차몰이 아예 싣지 않는다. 그래서 공정위 등록수보다 적다.)

### 돈까스·샌드위치는 공정위에 업종이 없다

공정위 중분류에 '돈까스' 칸이 없다. 돈까스 전문점이 **일식·서양식·기타 외식·분식·한식
다섯 칸에 흩어져** 있다. 그래서 공정위 등록 전수(총 9,000여 건)에서 영업표지에
`돈까스|돈가스|돈카츠|카츠` 가 든 것을 전부 뽑아(159건) 가맹점 수를 붙이고,
이름에 안 들어가지만 돈카츠 전문점인 곳(백소정·미소야·하루엔소쿠·사보텐)을 손으로 더했다.
샌드위치·토스트도 같은 방식이다(`샌드|토스트|베이글`, 분식·패스트푸드·기타 외식·서양식에 흩어짐).

## 4. 이번 조사에서 건진 교훈

### 4-1. "신메뉴 전용 페이지"가 있다고 신호인 건 아니다

세 번 속을 뻔했고 세 번 다 기각했다.

- **퀴즈노스** — 카드마다 `<span class="new_icon">…alt="new"` 가 붙는데 **66건 전부**다.
  숨김 처리라도 돼 있나 싶어 `/comm/css/sub.css` 를 직접 받아 봤더니 `display:none` 이 없다.
  2022년에 등록된 아메리카노·우유·소다까지 화면에 NEW 가 찍혀 있다. 배지를 버리고
  `#new` 칸 소속만 썼다.
- **돈까스클럽** — `/newmenu/new-menu.php` 라는 전용 페이지가 있는데, 항목 하나가
  포스터 이미지 1장이고 이름이 `alt="2026 신메뉴"` 다. 상품명이 글자로 존재하지 않는다.
- **101번지 남산돈까스** — 신메뉴 전용 탭에 10건이 실려 있는데, 메뉴 32장 중 31장이
  2023-05-08 한 시각 일괄 업로드고 공지·보도가 2021년에 멈췄다. 넣으면 3년 묵은 10건이
  통째로 신상이 된다.

세븐일레븐 '신상품' 탭 선례와 같은 종류다. **배지를 믿기 전에 전건 대비 몇 건에
붙었는지부터 세는 것**이 이 업종에서 가장 효과적인 방어였다.

### 4-2. 날짜 신호는 "분포"를 보고 판정한다

값이 있느냐가 아니라 **흩어져 있느냐**가 기준이다.

| 쓸 수 있었던 것 | 못 쓴 것 |
|---|---|
| 긴자료코 `REG_DT` — 2025-11-07:59 / 2026-04-09:2 / 2026-06-17:3 | 쑝쑝돈까스 — 34건 **전부 한 날짜** |
| 한솥 이미지 파일명 — 2019~2026 로 8년 분산, 미래 0 | 배터지는생동까스 — 전부 2022-02-14 |
| 하루엔소쿠 — 상품 id 순번과 Last-Modified 가 48건에서 **역전 0건** | 돈까스클럽 — 18장이 15.8시간 안에 전부 재업로드 |
| 원앤원 파일명 — 2020~2026, 미래 0 | 101번지 — 32장 중 31장이 한 시각 |
| 큰맘할매순대국 Last-Modified — **신상 5건만** 2026-03/06 으로 따로 떨어짐 | 큰맘할매순대국 고정 메뉴 20건 중 19건이 2025-12-22(사이트 구축일) |

⚠️ **imweb CDN 썸네일 경로 날짜는 썸네일을 다시 만들 때마다 바뀐다.**
`CANDIDATES-WESTERN.md` §2 가 쑝쑝돈까스에 대해 "당일 4건 실측 = 증분 업로드 증거"라고
적어뒀는데 오판이다. 그 4건은 상품이 아니라 로고였고, 문서 작성일에는 `20260930`,
이번 실측일에는 `20261001` 로 찍혔다. **그 노트를 고쳐야 한다.**

### 4-3. 403 이 다 봇 차단은 아니다

한솥 내부 API 는 POST 에 403 을 돌려준다. `notes/CANDIDATES-KOREAN.md` 가
"POST 전용 내부 API" 까지만 적고 멈춘 지점이다. 그런데 봇 차단이 아니라
**Spring Security 의 평범한 CSRF 방어**였다 — 메뉴 페이지가
`<meta name="_csrf_header" content="X-CSRF-TOKEN">` 와 `<meta name="_csrf" content="…">` 로
토큰을 그대로 내놓고, 같은 세션으로 그 헤더를 붙이면 200 이 온다. UA 위장도 로그인도 없이
109건을 받았다. **403 을 보면 CSRF 메타부터 찾아라.**

### 4-4. 이 규모대의 브랜드는 사이트가 없다

가맹점 40~70개 구간부터 급격히 무너진다. 일식 중위권 10곳 중 **6곳이 공식 사이트 자체가
없거나(만타스시31·타코아찌·카레세끼·라멘선생·참다랑어 막주는집·이라이타코야끼),
폐쇄·만료**다(이찌방라멘·어부김호권의청년어부). 돈까스 중위권도 14곳 중 13곳이
창업모집 랜딩이거나 메뉴가 통째로 이미지였다.

가맹점 수 순위를 끝까지 내려가도 더 건질 게 많지 않다는 뜻이다. 다음 조사는
순위를 더 내리는 것보다 **공공데이터포털 키를 받아 가맹점 수를 정확히 붙이는 쪽**이
투자 대비 효과가 크다.
