# 브랜드 후보 조사 — 양식·패밀리레스토랑 · 중식 · 돈까스 · 초밥/일식

`docs/BRAND-CANDIDATES.md` · `docs/CANDIDATES-KOREAN.md` 와 같은 형식이다. **어댑터는 없다.** 조사 결과일 뿐이다.

- 조사일: **2026-09-30**
- 조사 방법: 브랜드당 HTTP 5회 이내, 요청 간 2.5초, `collectors/base.client()` (UA `sinsang-note/1.0`)
- 조사 범위: robots.txt + 홈 + 메뉴 페이지 구조(+필요 시 JS 번들 1개). **전체 메뉴를 긁지 않았다.**

- 추측으로 채운 칸은 없다. 못 본 것은 "확인 못 함"이라고 적었다.

**빕스는 지시대로 조사하지 않았다**(robots 전면 차단, `BRAND-CANDIDATES.md` 기록 그대로).

> 조사를 시작할 때 그 파일이 없어서 피하지 못했다. **§0 에 두 문서의 대조표를 붙였다.**

### 미소야 충돌은 왜 생겼나

아임웹(imweb) 갤러리 위젯이 상품 캡션을 **`style="display:none"` 인 div 안에** 넣는다.

```html
<div id="caption_15786765" style="display:none">
  <h4><strong>로스카츠</strong></h4><p>담백한 육즙가득 등심<br />기본 : +밥+장국 …</p>
</div>
```

**렌더 텍스트만 뽑으면 0건으로 보이고, 원본 HTML 을 정규식으로 긁으면 57건이 나온다.**
`CANDIDATES-ASIAN.md` 의 "상품명 0건"은 렌더 텍스트 기준 판정으로 보인다.

같은 함정이 **쑝쑝돈까스**(같은 아임웹)에도 있다. `/menu` 는 879KB 인데 렌더 텍스트가 1,057자다.
**"렌더 텍스트가 짧다"를 "불가"의 근거로 쓰면 안 된다.** 아임웹 사이트는 반드시 원본 HTML 을 봐라.

## 2. 근거 (실측 조각)

추측과 구분하기 위해 실제로 받은 것을 남긴다.

### 스시로 — 이 조사 최고의 신호

`/pm` 은 **"이달의 한정메뉴"** 전용 경로다. 페이지 제목부터 그렇다.

```
<title>이달의 한정메뉴 | 스시로한국</title>
```

`/gm`(그랜드메뉴)이 **"일년 내내 다양하게 즐기는 200여개 상시 메뉴"**, `/pm` 이 **"이달에만 즐길 수 있는 한정 메뉴"** 로
사이트가 스스로 상시/한정을 갈라놨다. **`/pm` 에 있고 `/gm` 에 없으면 그게 이번 달 신제품이다.**
`is_new` 를 True 뿐 아니라 False 로도 확정할 수 있다는 뜻이고, 이건 본아이에프 `newYn` 과 같은 급이다.

마크업도 파싱하기 좋다. 데이터 속성에 다 들어 있다.

```html
data-menu-group="이달의 한정메뉴" data-menu-name-ko="광어 녹차소금"
data-menu-name-ja="ひらめ抹茶塩" data-menu-price="3,200"
data-menu-image="https://ssrkosupport.com/29990/002236.jpg"
```

`/pm` 은 **서버 페이지네이션**이다. 한 페이지 8건, 6페이지.

```html
<a class="page-link" href="/pm?page=2#limitedMenuSection">2</a>
```

→ `/pm?page=1..6` **6요청에 이달의 한정메뉴 약 48건**. `/gm` 은 **1요청에 437KB, 상시메뉴 전량**(카테고리 6종, `?category=4..9`).

`robots.txt` 는 **진짜 404** 다. 피자알볼로·GS25 같은 HTML 함정이 아니다.

```json
{"timestamp":"2026-09-30T11:39:05.800Z","status":404,"error":"Not Found","path":"/robots.txt"}
```

푸터에는 **이용약관 링크가 아예 없다.** 사업자만 적혀 있다 — `스시로한국 / 사업자 214-88-75700 / 대표이사 TANAKA SHUNSAKU`.
글로벌 본사(일본 FOOD & LIFE COMPANIES) 약관이 따로 걸릴 가능성은 **확인 못 했다.**

### 쑝쑝돈까스 — 이미지 업로드일이 살아 있다

`/menu` 1요청에 4개 카테고리가 전부 SSR 로 들어온다.

> 슈프림 돈까스 / 김치치즈 나베돈까스 / 양파듬뿍 돈까스 / 볶음우동 돈까스 / 옛날 왕 돈까스 …
> 등심(로스)돈까스 / 안심(히레)돈까스 / 모짜렐라 치즈돈까스 / 큐브치즈돈까스 …
> 유부우동 / 꼬지 어묵 우동 / 판모밀 / 냉모밀 / 짬뽕 우동 / 냉우동 …
> 까르보나라 / 로제파스타 / 매콤로제리조또볼파스타 / 미트볼 토마토 파스타 …

핵심은 이미지 CDN 경로의 날짜다. `cdn.imweb.me/thumbnail/YYYYMMDD/…` 를 세보면:

```
20250407: 136건   20231228: 4건   20260930: 4건   20250403: 2건   20210901: 1건   20240119: 1건
```

**`20260930` 은 조사 당일이다.** 대량 재업로드(`20250407` 136건) 위에 **당일 4건이 얹혀 있다** —
이게 증분 업로드가 실제로 일어난다는 증거다. 할리스·노브랜드버거처럼 전부 한 날짜로 뭉개진 경우와 다르다.

## 3. 도메인 함정 (§6 대응)

`BRAND-CANDIDATES.md` §6-1 이 경고한 그대로, 이번에도 실제로 틀린 게 나왔다.

> 회사는 서비스를 운영하면서 구축되는 데이터베이스에 robot.txt. 파일 등의 보호장치로서 이를 보호하고 있습니다.
> 따라서 robot.txt.로 보호되고 있는 데이터베이스에 접근하여 이를 수집하는 행위 및 다음의 행위를 불허합니다.
> ① 정당한 접근권한 없이 또는 허용된 접근권한을 넘어 회사의 정보통신망에 침입하는 행위 (ID, PW를 양도, 대여받아 사용하는 행위 포함)
> ② 회사의 상당한 투자나 노력으로 만들어진 성과를 이용하는 행위
> ③ 리버스엔지니어링, 디컴파일, 디스어셈블 및 기타 일체의 가공 행위를 통해 서비스 또는 데이터를 복제, 분해, 모방 또는 기타의 방법으로 변형하는 행위
> ④ **자동 접속 프로그램 또는 해킹 프로그램을 사용하는 등 회사가 제공하지 않은 일체의 크롤링 방법을 통하여 사이트나 서버에 접근하여 데이터를 수집, 이용하는 행위**
> ⑤ 서비스 이용목적을 벗어나 회사의 서버, DB 등 정보처리자원을 소모하게 하는 행위

⚠️ **읽는 순서가 중요하다.** 본문 첫 문장은 금지 대상을 "robot.txt.로 보호되고 있는 데이터베이스"로 한정하는데,
아웃백 robots 는 메뉴 경로를 **허용**한다. 여기까지만 보면 빠져나갈 여지가 있어 보인다.
**그러나 ④는 그 한정이 없다.** "회사가 제공하지 않은 **일체의** 크롤링 방법"이다. 이건 한솥도시락·폴바셋과 같은 등급이다.

또 하나 유보 — 이건 **회원약관**이고 주어가 회원이다. 비회원 공개 페이지 수집에 그대로 걸리는지는
한솥도시락 건과 똑같은 성격의 문제다. **사람이 정할 일이다.**
(같은 URL 의 `policyType=M` 은 위치기반서비스 약관, `policyType=Q` 는 개인정보처리방침이고 둘에는 관련 조항이 없다.)

### ⚠️ 쑝쑝돈까스 · 미소야 — robots 가 약관 경로를 막는다

둘 다 아임웹(imweb) 기반이라 robots 가 동일하다.

```
User-agent: *
Allow: /
Disallow: /site_join
Disallow: /site_join_agree
Disallow: /login
Disallow: /logout.cm
Disallow: /shop_cart
Disallow: /?mode*
Disallow: /admin
```

아임웹은 이용약관을 `/?mode=policy` 류 경로에 둔다. **`Disallow: /?mode*` 가 정확히 그걸 막는다.**
`CANDIDATES-KOREAN.md` 의 **김밥천국과 완전히 같은 상황**이다. robots 를 지키면 약관 원문을 받을 수 없다.
붙이기 전에 **사람이 브라우저로 직접 확인해야 한다.**

### ⚠️ 홍익돈까스 — robots 가 `/policy` 와 `/privacy` 를 막는다

```
User-agent: *
Allow: /
Disallow: /myPage
Disallow: /login
Disallow: /guide-default
Disallow: /policy
Disallow: /privacy
…
```

푸터에 `이용약관` 링크가 보이지만 경로가 `/policy` 다. 같은 유형이다.

### 스시로 — 약관 페이지가 없다

푸터의 링크가 `/story /pm /gm /to /store` 와 SNS 뿐이다. **약관·개인정보처리방침 링크가 아예 없다.**
없다는 건 금지도 아니지만 허용도 아니다. 지시대로 **글로벌 본사 약관이 더 엄격할 가능성**을 의심했는데,
`sushiro.co.kr` 에서 일본 본사 약관으로 가는 링크는 못 찾았다. **일본 FOOD & LIFE COMPANIES 쪽 약관은 확인 못 했다.**

### 나머지

**사보텐(캘리스코) · 매드포갈릭 · 서가앤쿡 · 투파인드피터 · 라화쿵부 · 짬뽕지존 · 쿠우쿠우 · 더본코리아**
— 약관을 **받지 않았다.** 브랜드당 5요청 한도를 robots·홈·메뉴에 썼다.
매드포갈릭은 푸터에 `TERMS OF SERVICE` 링크가 있는 걸 확인했으나 본문은 받지 않았다.

## 5. robots.txt 실측 결과

전부 `can_fetch()` 로 실측했다. **상태코드와 본문 유형을 같이 적는다.**

| 브랜드 | 상태 | 본문 | `can_fetch("/")` | 메모 |
|---|---|---|---|---|
| 아웃백 | 200 | text/plain | ✅ True | `.do` 2개만 Disallow |
| 더본코리아 | 200 | text/plain | ✅ True | `Allow: /` 뿐 |
| 매드포갈릭 | 200 | text/plain | ✅ True | `Allow: /` 뿐 (23바이트) |
| 캘리스코(사보텐) | 200 | text/plain | ✅ True | `Disallow:` **빈 값 = 전체 허용** |
| 서가앤쿡 | 200 | text/html ct 인데 본문은 규칙 | ✅ True | `Content-Type: text/html` 로 오는데 내용은 정상 robots. **ct 로 판단하지 마라** |
| 홍익돈까스 | 200 | text/plain (ISO-8859-1) | ✅ True | `/policy`·`/privacy` Disallow |
| 미소야 | 200 | text/plain | ✅ True | `/?mode*` Disallow |
| 쑝쑝돈까스 | 200 | text/plain | ✅ True | 미소야와 동일(아임웹) |
| 홍콩반점(파킹) | 200 | text/plain | ✅ True | **파킹 도메인의 robots 다.** `LLM-Policy:` 줄이 단서 |
| 투파인드피터 | 200 | text/plain | ✅ True | ⚠️ **`User-agent: Yeti` 규칙만 있다.** `*` 가 없어 우리 UA 는 매칭 안 됨 → 기본 허용 |
| 라화쿵부 | 200 | text/plain | ✅ True | ⚠️ 같은 문제. `Googlebot-Image`·`bingbot` 차단, `Yeti`·`NaverBot` 허용, **`*` 없음** |
| **애슐리** | 200 | text/plain | 🚫 **False** | **`User-agent: * / Disallow: /`**. Googlebot·NaverBot 만 부분 허용 |
| 스시로 | **404** | **application/json** | (규칙 없음) | 진짜 404. Spring Boot 에러 JSON |
| 쿠우쿠우 | **404** | **text/html** | (규칙 없음) | Apache 기본 404 HTML. **피자알볼로·GS25 유형** |
| 짬뽕지존 | **404** | **text/html** | (규칙 없음) | 같은 유형 |
| 갓덴스시(my.) | **404** | 빈 본문(0바이트) | (규칙 없음) | — |
| 탕화쿵푸 | **200** | **text/html (Cafe24 트래픽 초과 안내)** | (판단 불가) | ⚠️ **200 인데 robots 가 아니다.** 상태코드로 오판하기 딱 좋다 |
| TGI(파킹) | 200 | text/plain | ✅ True | **파킹 도메인이라 의미 없다** |

**새로 나온 유형 두 가지를 기록해 둔다.**

- **`User-agent: *` 규칙이 아예 없는 robots** (투파인드피터·라화쿵부).
  `robotparser` 는 매칭되는 그룹이 없으면 **허용**으로 판정한다. 파서상 허용이 맞지만,
  운영자가 특정 봇만 골라 허용한 의도는 **"열어둔 것"이 아니다.** 고봉민김밥인의 주석 처리 건과 같은 성격이다.
  `CRAWLING-POLICY.md` 기준대로 **더 보수적인 간격**을 잡아라.
- **호스팅 트래픽 초과 페이지가 200 으로 robots 자리에 오는 경우** (탕화쿵푸).
  기존에 기록된 "404 인데 HTML"(피자알볼로·GS25)과 달리 **상태코드까지 정상**이라 더 위험하다.
  robots 본문에 `User-agent` 가 없으면 파싱 결과를 믿지 마라.

## 6. 추천 순위 TOP 5

우선순위는 지시대로 **(1) 신제품 신호 → (2) 수집 난이도 → (3) 가맹점 수·인지도** 다.

### 1위. 스시로 — 이 조사에서 유일하게 "이번 달 신제품"이 구조로 갈려 있다

`/pm`(이달의 한정메뉴)과 `/gm`(상시 200여건)이 **사이트 설계 단계에서 분리**돼 있다.
차집합만으로 `is_new` 를 True·False 양쪽 확정할 수 있고, 이건 본아이에프 `newYn` 과 같은 급이다.
게다가 `data-menu-name-ko` / `data-menu-price` / `data-menu-image` 데이터 속성이라 파싱이 거의 공짜다.
robots 는 진짜 404, 약관 페이지 없음. **총 7요청**(`/pm` 6페이지 + `/gm` 1)에 전량이 들어온다.
공정위 미등록(직영)이라 가맹점 수는 안 잡히지만 인지도는 최상위다.
남은 리스크: **일본 본사 약관 확인 못 함.**

### 2위. 쑝쑝돈까스 — 가장 싸고, 증분 업로드가 실제로 돌고 있다

`/menu` **1요청**에 돈까스·우동·파스타·라이스 전 카테고리가 SSR 이다.
NEW 배지는 없지만 이미지 CDN 경로 날짜가 **조사 당일(`20260930`) 4건**을 포함해 분산돼 있다.
대량 재업로드 위에 증분이 실제로 얹히고 있다는 증거라 `uploaded_at` 신호로 쓸 수 있다.
가맹점 131개, 마스터의 `가맹본부 미확인 ⚠️` 도 이 조사에서 `(주)SSPC` 로 해소했다.
남은 리스크: **약관을 robots 가 막는다.**

### 3위. 미소야 — 상품 텍스트 품질이 제일 좋다

`/menu` 1요청, 상품명 + 구성 설명까지 SSR. 가맹점 **180개**로 이 조사에서 신호 있는 브랜드 중 가장 크다.
이미지 업로드일이 2023~2026 으로 넓게 퍼져 있어 증분 신호로 쓸 만하다.
2위가 아닌 이유는 **가격이 없고** 신호가 배지가 아니라 이미지 날짜 추정이라서다.
약관 상황은 쑝쑝돈까스와 동일(robots 차단).

### 4위. 사보텐 — 신호는 없지만 캘리스코 4개 브랜드가 딸려온다

번들 한 파일(1.6MB)에 메뉴가 통째로 들어 있어 **브랜드당 2요청**(홈에서 번들 경로 읽기 + 번들)이면 끝난다.
robots 가 완전 개방(`Disallow:` 빈 값)이고, 같은 번들에 **히바린·타코벨코리아·리퍼크**까지 있다.
**신제품 신호가 없다는 게 결정적 약점**이라 4위다. 합류 첫날 신제품 0건이다.
번들 해시가 배포마다 바뀌는 것도 운영 부담이다.

### 5위. 투파인드피터 — 더 나은 후보가 없어서 들어온다

이미지 파일명이 한글 상품명이라 **상품 목록은 만들 수 있다.** 그게 전부다.
가격·설명·출시일이 없고 신제품 신호도 없다. 가맹점 32개.
robots 에 `User-agent: *` 가 없다는 유보도 있다. **넣을지 말지는 운영자 판단이다.**

### TOP 5 에 넣지 않은 이유

가장 가까운 게 스시로의 **"이달의 한정메뉴" 라는 월 단위 분류**인데, 그건 날짜가 아니라 분류다.

## 8. 어댑터를 쓸 사람에게 넘기는 주의사항

1. **`BRANDS` 레지스트리에 세부분류를 먼저 등록해야 한다.** 이 후보들은 기존에 없는 분류다 —
   초밥(스시로·쿠우쿠우), 돈까스(쑝쑝돈까스·사보텐·미소야), 양식/패밀리레스토랑(아웃백·투파인드피터),
   중식(짬뽕지존·라화쿵부). `base.py` 의 `BRANDS` 한 곳에서 정하는 원칙은 유지해라.
   ⚠️ **미소야는 공정위 업종이 `일식` 이지만 실제는 돈까스 전문점**이다. `FRANCHISE-MASTER.md` §7-4 가 경고한 그대로다.
2. **아웃백은 약관 판단이 끝나기 전에 붙이지 마라.** §4 참고. 조항 ④에 robots 한정이 없다.
3. **쑝쑝돈까스·미소야·홍익돈까스는 약관을 못 봤다.** robots 가 약관 경로를 막는다.
   김밥천국과 같은 건이고, 사람이 브라우저로 확인해야 한다.
4. **아임웹(imweb) 사이트는 렌더 텍스트로 판정하지 마라.** 미소야·쑝쑝돈까스 둘 다
   상품 캡션이 `style="display:none"` div 안에 있어서 렌더 텍스트가 1,000자대로 나온다.
   원본 HTML 을 정규식으로 긁어야 상품이 보인다. §0 참고. **`CANDIDATES-ASIAN.md` 가 이걸로 미소야를 오판했다.**
5. **이미지 파일명·CDN 경로 날짜를 `released_at` 에 넣지 마라.** `BRAND-CANDIDATES.md` §6-5 대로 `uploaded_at` 까지다.
