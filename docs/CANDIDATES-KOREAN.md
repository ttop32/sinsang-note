# 브랜드 후보 조사 — 한식 · 분식 · 도시락

`docs/BRAND-CANDIDATES.md` 와 같은 형식이다. **어댑터는 없다.** 조사 결과일 뿐이다.

- 조사일: **2026-09-30**
- 조사 방법: 브랜드당 HTTP 5회 이내, 요청 간 2초 이상, `collectors/base.client()` (UA `sinsang-note/1.0`)
- 조사 범위: robots.txt + 홈 + 메뉴 페이지 구조. **전체 메뉴를 긁지 않았다.**
- robots 는 전부 `urllib.robotparser.can_fetch()` 로 실측했다. 상태코드와 본문이 HTML 인지도 같이 봤다.
- 추측으로 채운 칸은 없다. 못 본 것은 "확인 못 함"이라고 적었다.

이미 처리된 이삭토스트(수집 중)는 제외했다. 다른 에이전트가 맡은 베이커리·일식·중식·카페·주점은 건드리지 않았다.

**앞선 조사에서 "공식 도메인 특정 불가"였던 김밥천국을 다시 시도해 찾았다.** (§3 참고)

## 2. 근거 (실측 조각)

추측과 구분하기 위해 실제로 받은 것을 남긴다.

### 본아이에프 — 이 카테고리 최고의 신호

`www.bonif.co.kr/brand/menu?brdCd=BF104` 의 HTML 은 jsrender 템플릿만 있고 상품이 없다. 그런데 그 템플릿이 필드명을 알려준다.

```html
{{if newYn == 'Y'}}
   <li><img src="/assets/web/front/assets/images/icons/badge-ne…
```
```html
<li><a href="javascript:menu.selectOrderBy('NEW')">신메뉴</a></li>
```

`/static/js/common/api/menu.js` 에 엔드포인트가 그대로 있다.

```js
const API_DOMAIN = "https://api.bonif.co.kr";
/brand/v1/menu?<query>          // 메뉴 리스트
/brand/v1/menu/detail?brdCd=&cmdtIdx=
/brand/v1/category?brdCd=
/brand/v1/badge
```

`GET https://api.bonif.co.kr/brand/v1/menu?brdCd=BF104` → **200, 상품 80건**. 응답은 XML 이다.

```xml
<brdNm>본도시락</brdNm>
<cmdtIdx>540355</cmdtIdx><cmdtNm>크림새우 게살볶음밥</cmdtNm><newYn>Y</newYn><bestYn>N</bestYn>
```

80건 중 `newYn=Y` 가 여럿, `N` 이 다수다. **`is_new` 를 True 뿐 아니라 False 로도 확정할 수 있다.**
카테고리 페이지 신호(빽다방·던킨형)보다 한 단계 위고, 배지 신호(폴바셋·설빙형)와 같은 급이다.

브랜드 코드는 8개다. `BF101 BF102 BF104 BF105 BF107 BF111 BF113 BF114`
→ 본죽&비빔밥 · 본죽 · **본도시락** · 본설렁탕 · 본우리반상 · 멘지 · 본흑염소·능이삼계탕 · 이지 브레드&커피
(코드와 브랜드의 1:1 대응은 `BF104=본도시락` 만 응답의 `<brdNm>` 으로 확인했다. 나머지 7개는 **확인 못 함.**)

**다만 `released_at` 은 못 채운다.** 응답의 `regDt`/`updDt` 는 브랜드 단위로 1개씩만 있고 상품별 날짜 필드는 없다.
`/brand/v1/menu/detail` 에 있는지는 **확인 못 함.**

### 김밥천국 — 앞선 조사의 미확인 항목 해소

`kimbab1009.com` 이 맞다. 푸터가 신원을 확인해 준다.

```
김밥천국 서울시 서초구 사임당로 52  상표디자인번호 : 41-0165887-0000
사업자등록번호 214-88-85173  전화 1577-6323 , 02-581-6323
```

**상표디자인번호가 찍혀 있는 곳**이라 "상표를 공유하는 법인이 여럿"이던 문제에서 이 도메인을 고를 근거가 된다.
다만 동일 상표를 쓰는 다른 법인(예: `kimbabcheongug.co.kr` = 정다믄 김밥천국)이 여전히 존재한다는 사실은 변하지 않는다.

메뉴 분류가 `신메뉴 / 김밥 / 식사 / 분식 / 돈까스 / 계절메뉴` 이고 **신메뉴가 `/31` 로 분리돼 있다.**
`/31` 은 SSR 이고 상품명이 실제로 들어 있다.

> 까르보나라 / 까르보라면 / 까르보떡볶이 / 해물파스타 까르보나라 / 매운볶음우동 /
> 새우제육덮밥 / 나가사키라면 / 상하이떡볶이 / 철판볶음라면 / 해물볶음우동돈까…

**⚠️ 약관을 확인하지 못했다.** 푸터의 이용약관 링크가 `/?mode=policy` 인데 robots 가 `Disallow: /?mode*` 다.
robots 를 지키면 약관 원문을 받을 수 없다. 붙이기 전에 사람이 브라우저로 직접 확인해야 한다.

### 바르다김선생 — 홈이 신메뉴 페이지보다 낫다

`/menu/new.html` 은 200 이지만 렌더 텍스트 407자에 상품이 없다(JS 렌더).
반면 **홈이 신메뉴를 SSR 로 내놓는다.**

> 신메뉴 출시 **강릉 장칼국수** 북어육수에 특제 장 소스로 칼칼하고 진한 국물이 일품!
> 신메뉴 출시 **눈꽃치즈 닭갈비 덮밥** 100% 닭다리살로 만든 매콤한 양념 닭갈비에 부드러운 눈꽃치즈가 듬뿍!
> 신메뉴 출시 **바른 참기름 막국수** 바른 참기름과 특제 간장소스, 다양한 고명의 감칠 맛이 좋은 메밀 국수

"신메뉴 출시" 문구가 상품마다 붙어 있어 그대로 `is_new` 로 쓸 수 있다.
전체 메뉴는 `/menu/list.html?bs=004001 · 004002 · 004004 · 004005 · 004006 · 004007` 6개다.

### 죠스떡볶이 — 배지가 실재한다

```html
<h3 class="tit">죠스떡볶이</h3>
<p class="desc">한 입에 쏙! 배려심 깊은 3.5cm의 떡</p>
<div class="badge"><div class="new">NEW</div></div>
```
`/menu/menu.html` 9건 중 1건에만 붙어 있다. 켜고 끄는 배지라는 뜻이라 신호로 쓸 만하다.
`/menu/setmenu.html`·`/menu/side.html` 의 배지 유무는 **확인 못 함.**

### 한솥도시락 — 신호는 좋은데 약관이 막는다

`/menu/menu_list` 의 카테고리에 **"신메뉴"와 "10월 신메뉴"** 가 둘 다 있다.
월 단위로 갈리는 신메뉴 분류는 이 카테고리에서 가장 선명한 신호다.

그런데 상품은 HTML 에 없고 AJAX 다.
```js
url: "/api/menu/menu_list/" + cate1 + "/" + cate2
```
`GET /api/menu/menu_list/0/0` → **HTTP 405 Method Not Allowed**. POST 전용이다.
`cate1`/`cate2` 의 실제 값은 같은 API 응답(`data.cate1Info.idx`)에서 오므로 **GET 으로는 끝내 알 수 없다.**

### 신전떡볶이 — 신호는 없지만 수집은 가장 싸다

`/doc/menu01.php` 한 페이지에 전체가 들어 있다.
> 떡볶이 치즈떡볶이 모듬튀김 오뎅 만두 잡채말이 김말이 치즈스틱 신전김밥 스팸마요 컵밥 참치마요 컵밥 신전라이스 얼큰오뎅 토스트

nav 는 `menu01`~`menu06` 인데 이름이 `기본메뉴 / 음료·빙수 / 떡볶이 / 튀김 / 라이스 / 기타` 다. **신메뉴 분류가 없다.**

### 국수나무 — 시즌메뉴는 신제품 분류가 아니다

`cat_no=1..7` = `정식 / 생면 / 면 / 밥 / 돈까스 / 시즌메뉴 / 곁들임`. 전부 SSR 이고 설명까지 온다.
NEW 배지 클래스는 하나도 없다. **파스쿠찌의 "시즌음료"와 같은 처지다** — 계절 분류지 신제품 분류가 아니다.

상품 이미지가 `/uploaded/product/{id}/large_{hash}.jpg` 라 `id` 가 등록순일 **가능성**은 있다(35, 37~40, 69~74 관측).
미스터피자 `wr_id` 와 같은 수준의 추정이고 **실측하지 않았다.**

### 엽기떡볶이 — 붙이면 안 된다

```
User-agent: *
Disallow: /

User-agent: Yeti
Allow: /

User-agent: Googlebot
Allow: /
```
`urllib.robotparser.can_fetch("*", "https://www.yupdduk.com/")` → **False**.
빕스와 같은 건이다. 순위 문제가 아니다.

### 더본코리아 계열 — 개별 사이트가 없다

`start.theborn.co.kr` 가 나열하는 브랜드는 18개다.
> 빽보이피자 역전우동 빽다방 홍콩반점 롤링파스타 한신포차 백스비어 새마을식당 제순식당
> 리춘시장 인생설렁탕 막이오름 원조쌈밥집 본가 고투웍 연돈볼카츠 돌배기집 미정국수0410

전부 **창업 안내 페이지**고 메뉴 목록이 없다. 인생설렁탕(`?bc=18`)을 열어 확인했는데
"설렁탕 / 얼큰해장국 / 옛날불고기 / 직화제육볶음" 이 창업 홍보 문구 안에 섞여 있을 뿐 상품 목록이 아니다.

앞선 조사의 결론(`theborn.co.kr` 는 브랜드 소개 포털이고 메뉴가 없다)이 그대로 유지된다.
**빽다방이 더본 계열 중 유일하게 자체 메뉴 사이트를 가진 브랜드다.**

| **엽기떡볶이** | `yupdduk.co.kr` (NXDOMAIN) | — | `yupdduk.com` (단, robots 로 차단됨) |

**`새마을식당`** 은 `saemaul.co.kr` 이 DNS 로 살아 있으나 더본코리아 것인지 **확인하지 않았다**(요청을 보내지 않았다).
더본이 개별 브랜드 사이트를 두지 않는다는 사실로 보아 무관한 사이트일 가능성이 높다. 건드리지 마라.

## 4. 이용약관

robots 허용 + 약관 금지 조합을 다시 찾았다.

### 🚫 한솥도시락 — 폴바셋과 같은 유형

`hsd.co.kr/footer/agreement` 원문이다.

> **제 16 조 (회원의 의무)** ① 회원은 서비스를 이용함에 있어 다음 각 호의 행위를 하여서는 안됩니다.
> … 11. **회사의 서비스를 이용하여 얻은 정보를 회사의 사전 승낙 없이 복제 또는 유통시키거나 상업적으로 이용하는 행위**

> **제 17 조 (지적재산권 등)** ① 회사가 작성하여 제공하는 서비스에 관한 저작권 및 기타 지적재산권은 회사에 속합니다.
> 회원은 회사가 제공하는 서비스를 **회사의 사전동의 없이 영리 목적으로 복제, 전송, 출판, 배포, 방송 기타 방법에 의하여 이용**하거나 제3자에게 이용하게 하여서는 안됩니다.

`base.py` 주석에 적힌 폴바셋 제외 사유("정보를 회사의 사전 승낙 없이 복제 또는 유통하거나 상업적으로 이용하는 행위")와
**문구가 사실상 동일하다.** 폴바셋을 뺐다면 한솥도 같은 기준으로 빼야 일관된다.

한 가지 유보는 달아 둔다. 두 조항 모두 주어가 "**회원은**"이다. 우리 봇은 회원가입을 하지 않는다.
이마트24(제8조⑧)는 주어가 "이용자"였고 크롤러를 명시했지만 한솥은 그렇지 않다.
**이 차이를 근거로 삼을지는 사람이 판단할 일이다.** 조사자가 정할 문제가 아니라서 원문을 그대로 옮겼다.

### ✅ 바르다김선생 — 금지 조항 없음

`teacherkim.co.kr/footer/term.html` 전문에서 `크롤 / 스크 / 매크로 / 스파이더 / 로봇 / 자동화 / 복제 / 배포 / 상업적 / 영리` 를
전부 검색했다. 걸린 것은 개인정보 수집·이용 동의 조항(제7조~제8조)뿐이고 **스크래핑·복제·영리이용 금지 조항이 없다.**

### ⚠️ 김밥천국 — 확인할 수 없었다

약관 링크가 `/?mode=policy` 인데 robots 가 `Disallow: /?mode*` 다. robots 를 지키면 못 받는다.
**"약관 없음"이 아니라 "확인 못 함"이다.** 사람이 브라우저로 봐야 한다.

### 나머지

죠스떡볶이·국수나무·신전떡볶이·명륜진사갈비·두끼·배떡·한촌설렁탕의 약관은 **확인하지 않았다.**
요청 예산을 메뉴 구조 파악에 썼다. 실제로 붙일 브랜드는 약관을 따로 확인해야 한다.

**robots.txt 가 없는 곳이 7곳이다.** 부재는 금지가 아니지만 허용도 아니다. `CRAWLING-POLICY.md` 기준대로 더 보수적인 간격을 잡아라.

```
#User-agent: *
#Disallow: /
#Allow: /renewal/03_menu
…
User-agent: Yeti
Allow: /renewal/
```

파서상으로는 `*` 그룹이 없어 `can_fetch('*', …)` 가 **True** 로 나온다. 그러나 **주석의 의도는 명백히 "`/renewal/` 외 전부 차단"** 이다.
굽네치킨 `/menu/new.jsp` 건과 같은 종류다. 규칙상 허용이라고 그냥 긁지 마라.

## 6. 추천 순위 TOP 8

기준 순서는 **(1) 신제품 신호 → (2) 수집 난이도 → (3) 브랜드 관심도** 다.

| # | 브랜드 | 근거 | 예상 요청 수 |
|---|---|---|---|
| 1 | **본도시락 / 본죽 / 본죽&비빔밥** (본아이에프) | 이 카테고리에서 **유일하게 상품별 NEW 플래그(`newYn`)를 구조화된 API 로 준다.** `is_new` 를 True 와 False 양쪽으로 확정할 수 있어 배지 신호 중에서도 상급이다. **1요청에 80건**이고 한 API 로 8개 브랜드가 붙는다. 수집 효율이 조사 전체 1위 | 브랜드당 **1** (총 8) |
| 2 | **김밥천국** | 신메뉴가 **URL 로 분리**돼 있고(`/31`) SSR 이라 파싱 위험이 가장 낮다. 분식 인지도는 이 목록 최고다. ⚠️ **약관을 못 봤다** — 붙이기 전 확인 필수라 1위로 못 올렸다 | 6 (분류 수) |
| 3 | **바르다김선생** | "신메뉴 출시" 라벨이 상품마다 붙어 SSR 로 온다. 신메뉴 전용 페이지는 JS 렌더라 못 쓰지만 **홈 1요청이 그 역할을 대신한다.** 약관을 확인했고 금지 조항이 없다 — 이 목록에서 유일하다 | 1~7 |
| 4 | **죠스떡볶이** | NEW 배지가 실제로 켜고 꺼진다(9건 중 1건). SSR 3페이지면 끝난다. robots.txt 가 없어 보수적 간격이 필요하고, 나머지 2페이지의 배지 유무를 확인 못 해 4위 | 3 |
| 5 | **국수나무** | 신제품 신호는 **없다.** 대신 상품명+설명까지 SSR 로 완전하게 오고 7요청이면 전부 끝난다. 한식/면류 카테고리가 지금 비어 있어 채우기용으로는 가장 깔끔하다. **합류 첫날 신제품 0건**은 감수해야 한다 | 7 |
| 6 | **신전떡볶이** | 마찬가지로 신호가 없다. 다만 **1요청에 전체 메뉴**라 수집 비용이 조사 전체 최저다. 노브랜드버거와 같은 위치인데 이미지 날짜조차 없어 한 단계 아래 | 1~2 |
| 7 | **한솥도시락** | 신호만 보면 2위권이다("10월 신메뉴" 카테고리). 그런데 **약관이 폴바셋과 같은 유형이고**, 게다가 상품 API 가 POST 전용이라 GET 으로는 못 받는다. 신호가 좋아 목록에는 남기지만 **약관 판단이 먼저다** | 확인 못 함 |
| 8 | **한촌설렁탕** | 신호 유무를 **확인 못 했다.** 메뉴 경로(`/new/html/menu_1.html`)까지만 찾고 예산이 끝났다. 설렁탕 카테고리가 비어 있어 후속 조사 가치는 있다 | 확인 못 함 |

### TOP 8 에 넣지 않은 이유

- **명륜진사갈비 · 두끼** — 무한리필 뷔페라 **애초에 상품 목록이라는 게 없다.** 두끼는 가격표뿐이고,
  명륜은 메뉴소개가 단일 페이지 앵커(`/page/11#s11_2`)다. 홈 NEWS 에 "글로벌 신메뉴 출시!"가 있지만
  **게시글이지 상품이 아니다.** KFC `/promotion/newMenu` 를 뺀 것과 같은 이유다.
- **배떡 · 청년다방 · 고봉민김밥인** — 전부 상품이 HTML 에 없다. 배떡은 Imweb 빌더,
  청년다방 도메인은 창업 사이트, 고봉민은 스플래시다.
- **더본코리아 계열** — 개별 메뉴 사이트가 존재하지 않는다. 붙일 대상 자체가 없다.
- **엽기떡볶이** — robots 가 우리를 명시적으로 막는다. **순위 문제가 아니라 붙이면 안 된다.**
- **놀부 · 명랑시대쌀핫도그 · 육회한판** — 공식 사이트에 도달하지 못했다.

## 7. 신제품 신호가 확실한 브랜드 (요약)

붙는 날부터 신제품을 내놓을 수 있는 곳이다.

| 신호 종류 | 브랜드 |
|---|---|
| **출시일 (`released_at`)** | **없음** — 이 카테고리엔 한 곳도 없다 |
| **NEW 배지 (`is_new` True/False 양쪽)** | 본아이에프 8종 (`newYn`), 죠스떡볶이 (`div.new`) |
| **신제품 전용 페이지·카테고리** | 김밥천국(`/31`), 바르다김선생(홈 "신메뉴 출시" + `/menu/new.html`), 한솥도시락("신메뉴/10월 신메뉴", 단 API 가 POST) |
| 계절 분류만 (신제품 아님) | 국수나무(시즌메뉴), 김밥천국(계절메뉴) |
| **없음** | 신전떡볶이, 명륜진사갈비, 두끼 |
| 확인 못 함 | 한촌설렁탕, 고봉민김밥인, 명랑시대쌀핫도그, 놀부, 육회한판 |

**이 카테고리에는 `released_at` 을 채울 수 있는 브랜드가 없다.** 이삭토스트 `prdcode` 같은 건 나오지 않았다.
본아이에프 `/brand/v1/menu/detail` 에 상품별 날짜가 있을 가능성은 남아 있으나 **확인 못 했다.**

## 8. 어댑터를 쓸 사람에게 넘기는 주의사항

1. **본아이에프 API 응답은 XML 이다.** `Accept: application/json` 으로 JSON 이 오는지는 **확인 못 했다.**
   XML 그대로 파싱해도 되지만, 먼저 JSON 을 시도해 보는 게 낫다.
2. **본아이에프 브랜드 코드 8개 중 7개는 이름을 확인하지 않았다.** `BF104=본도시락` 만 응답의
   `<brdNm>` 으로 확인했다. 나머지는 `/brand/v1/category` 나 각 코드의 응답으로 실측해라.
   `BRANDS` 에 등록하기 전에 반드시 이름을 맞춰야 한다.
3. **`api.bonif.co.kr` 에는 robots.txt 가 없다.** `/robots.txt` 가 400 과 함께
   `No endpoint GET /robots.txt` 라는 **API 에러 응답**을 돌려준다. 200 이 아니니 오판할 일은 없지만,
   www 쪽 robots 가 404 로 **47KB HTML** 을 주는 건 피자알볼로·GS25 와 같은 함정이다. 상태코드를 봐라.
4. **한솥도시락은 약관 판단이 끝나기 전에 붙이지 마라.** §4 참고. 조항 주어가 "회원은"이라는
   유보가 있지만 그건 사람이 정할 문제다.
5. **김밥천국은 약관을 못 봤다.** robots 가 약관 경로를 막고 있다. 사람이 브라우저로 확인해야 한다.
   또 동일 상표를 쓰는 다른 법인(`kimbabcheongug.co.kr` 등)이 여전히 존재하니, 어느 날 메뉴가
   통째로 달라 보이면 도메인을 다시 확인해라.
6. **고봉민김밥인 robots 의 주석을 읽어라.** 파서는 허용이라 하지만 주석은 차단 의도다(§5).
   굽네치킨 `/menu/new.jsp` 와 같은 건이다.
7. **`BRANDS` 레지스트리에 세부분류를 먼저 등록해야 한다.** 이 후보들은 기존에 없는 분류다 —
   도시락(본도시락·한솥), 한식(국수나무·한촌설렁탕), 분식(김밥천국·바르다김선생·죠스떡볶이·신전떡볶이).
   분식은 이삭토스트로 이미 등록돼 있다. `base.py` 의 `BRANDS` 한 곳에서 정하는 원칙은 유지해라.
8. **한촌설렁탕은 호스트 순회가 필요하다.** apex `hanchon.kr` 가 구형 TLS 라 `SSL: UNSUPPORTED_PROTOCOL`
   로 죽는다. 설빙 `sulbing.com` 과 같은 종류이고, 스타벅스 `_live_host()` 같은 장치가 있어야 한다.

## 9. 확인 못 한 것

- **본아이에프 브랜드 코드 7개의 이름** (`BF101 BF102 BF105 BF107 BF111 BF113 BF114`)
- **본아이에프 `/brand/v1/menu/detail` 에 상품별 출시일이 있는지** — 있으면 이 카테고리 유일의 `released_at` 이 된다
- **본아이에프 API 의 JSON 지원 여부**
- **한솥도시락 `/api/menu/menu_list` 의 POST 파라미터와 `cate1`/`cate2` 값** — GET 은 405 라 알 수 없었다
- **김밥천국 이용약관** — robots 가 `/?mode*` 를 막아 받지 못했다
- **한촌설렁탕 메뉴 페이지 내용** — `/new/html/menu_1.html` 경로까지만 찾았다
- **죠스떡볶이 `/menu/setmenu.html`·`/menu/side.html` 의 NEW 배지 유무**
- **고봉민김밥인 메뉴 경로** — `/renewal/03_menu/menu01.php` 는 404. robots 주석이 `/renewal/03_menu` 를
  가리키므로 그 아래 어딘가일 것이나 못 찾았다
