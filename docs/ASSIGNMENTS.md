## 2. 검수 — 모든 묶음에 공통

사용자 지시로 **모든 코드 작업은 검수자(`a4d4c8a36706467bc`)와 짝지어 진행한다.**
아래 4단계를 거치지 않은 작업은 미완성이다.

| 단계 | 누가 | 무엇을 |
|---|---|---|
| **① 변경 전 스냅샷** | 작업자 | 손댈 수치를 **먼저** 재서 기록한다. `BACKLOG.md` §4 재현 스크립트를 쓴다 |
| **② 변경 + 변경 후 스냅샷** | 작업자 | 같은 스크립트로 다시 잰다. **차집합(사라진 것·새로 생긴 것)을 전건 출력**한다 |
| **③ 독립 재현** | 검수자 | **작업자 보고를 믿지 않는다.** 직접 돌려 수치를 다시 세고, 화면 변경은 **브라우저로** 확인한다. 결과를 `docs/QA-REPORT.md` 에 쓴다 |
| **④ 판정 → 커밋** | 검수자 → 작업자 | 통과/조건부/반려. 통과한 것만 커밋·푸시한다 |

### 2-1. 전 묶음 공통 완료 판정 기준

어떤 묶음이든 아래를 **전부** 만족해야 통과다.

1. **사라진 신제품 0건.** 변경 전 화면에 있다가 없어진 상품을 전건 나열하고, 하나하나 왜 빠져야 하는지 적는다.
   *(근거: 괄호 제거로 미스터피자 9건이 흡수됨 · 기준선 가드로 빽다방 11건·설빙 14건이 통째로 사라짐 ·
   비식품 단어 `핸디` 로 스타벅스 젤리 2건이 사라짐 — **침묵하는 실패가 이 프로젝트의 주된 사고 유형이다**)*
2. **화면 조작 실측.** 탭·검색·정렬을 **실제로 눌러** 카드 수가 줄어드는지 본다.
   *(근거: 같은 증상이 2번 터졌다 — 1차 CSS, 2차 JS. 두 번 다 우연히 발견됐다)*
3. **여러 줄 코드에 부분 문자열 치환 금지.** JS·CSS 가 2번 깨졌다.
   블록 단위로 바꾸고, 바꾼 뒤 **빌드 산출물의 콘솔 에러 0건**을 확인한다.
4. **`git status` 가 깨끗**하고, 그 묶음 외의 파일이 커밋에 섞이지 않았다.
5. 추정으로 채운 값이 없다. 모르면 `None`·빈 문자열·"확인 불가"로 남긴다.
